# Мультиплеер

## Принцип

У каждого игрока — **свой личный Лагерь** со своей прокачкой и прогрессом. Мультиплеер встроен в виде **Перекрёстков Глубин** — общих пространств, возникающих каждые 5 ярусов.

---

## Цикл ярусов

```
Ярус 0–4:   личная кампания
Ярус 5:     Перекрёсток Глубин
Ярус 6–9:   личная кампания
Ярус 10:    Рубеж (Перекрёсток замещён)
Ярус 11–14: личная кампания
Ярус 15:    Перекрёсток Глубин
...
```

**Ярус 0 (Пролог — Бездна) учитывается в цикле.**

**Рубеж замещает Перекрёсток:** на тирах 10, 20, 30… многопользовательская локация Перекрёстка не создаётся — вместо неё открывается пространство Рубежа с мегабоссом и нарративным событием.

---

## Доступ к Перекрёсткам вне сессии

После первого Перекрёстка в Лагере появляется **Портал Перекрёстков**. Через него в любое время (между сессиями) можно попасть на любой из уже посещённых Перекрёстков.

---

## Асинхронный мультиплеер (виден всегда)

| Механика | Описание |
|----------|----------|
| Призраки | Тени погибших игроков на этажах; подсказка об опасности |
| Надписи на стенах | Оставлены другими игроками |
| Могилы | Место гибели другого игрока → предмет-«эхо» → случайный лут |

---

## Перекрёстки Глубин (активный мультиплеер)

| Зона | Функция |
|------|---------|
| Торговая площадь | Прямая P2P торговля между игроками |
| Арена | PvP-дуэли; подробнее: [ArenaSystem.md](ArenaSystem.md) |
| Доска найма | Поиск пати для ближайшего яруса |
| Галерея Лордов | Витрина топ-игроков; их персонажи стоят как статуи |

## Co-op

> ⚠️ **Функция не входит в первый релиз. Детальный дизайн — отдельный этап.**

Планируемые принципы:
- Пати 2–3 человека для совместного прохождения яруса
- Сложность масштабируется под количество игроков
- При гибели участника: попытка завершена, ярус ему не засчитывается. Может остаться наблюдателем или выйти. При успехе пати — получает часть наград.
- XP в co-op: *требует дизайна (делится или каждый получает полный)*
- Уникальный co-op лут в некоторых ярусах
