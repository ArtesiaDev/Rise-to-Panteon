# Дерево эволюции

## Принцип

Персонаж эволюционирует через поглощение жизненных сил врагов. Эволюция никогда не сбрасывается — это фундамент долгосрочного прогресса (единственное исключение — добровольный Престиж после Стадии 6).

---

## Механика в сессии

- XP накапливается в бою
- Если уровень достигает порога следующей стадии **прямо во время сессии** — XP перестаёт расти
- Перейти на новую стадию можно только через **Алтарь Эволюции** в Лагере (открывается с Яруса 1)
- В бою эволюционировать нельзя

Это мотивирует регулярно возвращаться в Лагерь.

---

## Стадии

```
СТАДИЯ 0: Искра                   Уровни 1–10
  └─ Бесформенная светящаяся точка. Нет рук, нет тела.
     Движется как шар света. Атакует импульсами.

СТАДИЯ 1: Сгусток                 Уровни 11–25
  └─ Начинают проявляться очертания. Тёмный сгусток с ореолом.
     Первые примитивные конечности. Можно использовать предметы.

СТАДИЯ 2: Тень                    Уровни 26–45
  └─ Гуманоидный силуэт без чётких черт. ПЕРВЫЙ ВЫБОР ПУТИ.
```

На Стадии 2 игрок выбирает один из четырёх путей. Выбор необратим в рамках текущего прогресса (другие пути — через Престиж).

## Стадия 6: Вознесённый (Уровни 151+)

Финальная форма. Всего **8 вариантов** — уникальный для каждой ветки Стадии 5. Монументальный визуал, специальные эффекты.

- Первые в мире, достигшие каждого варианта — занесены в мировой Пантеон навсегда
- Открывает Престиж-систему (опционально)
