# Структура подземелья

## Иерархия измерений

Каждый **Ярус** — отдельное измерение со своим биомом, экосистемой и правилами. Переход через **Врата Резонанса** — смена реальности, а не просто следующий этаж. Биом меняется с каждым ярусом.

## Структура этажей внутри яруса

```
Этаж 1:              Вход в измерение, обычные враги
...
Каждые 5 этажей:     Мини-босс
...
Последний этаж:      Страж Порога → Врата Резонанса → портал в Лагерь
```

**Правило совпадения:** если цикл мини-босса совпадает с последним этажом яруса — Страж Порога замещает мини-босса.

### Мини-боссы
Не уникальные персонажи. Это обычный моб яруса, который поглотил достаточно других, чтобы разрастись до размеров комнаты. Механически интереснее рядового врага, но без нарратива.

### Страж Порога
Каждый уникален: имя, короткий диалог перед боем, собственная механика фазы.
Лорно: стражи — существа, занявшие место у Врат Резонанса, чтобы не пропустить слабых. Их убийство открывает проход в следующее измерение.

## Грандиозные Рубежи

Каждые **~10 ярусов** — Рубеж: ярус с мегабоссом, крупным нарративным поворотом и мировым событием.

- Рубеж **замещает** Перекрёсток Глубин на том же тире (тиры 10, 20, 30…)
- Первые в мире, прошедшие Рубеж — заносятся в **мировой Пантеон** навсегда
- Внутренняя структура Рубежа (уникальные механики) — *отдельный этап дизайна*

## Генерация этажей

**Гибридный подход:**
- **Фиксировано:** комната Стража Порога, нарративные точки, секретные сюжетные комнаты, Врата Резонанса
- **Процедурно:** планировка обычных этажей, расположение врагов, стандартный лут

**Seed:**
- Личная кампания — уникальный seed на каждую попытку
- Рейтинговый режим — фиксированный seed на сезон (1 месяц); подробнее: [SeasonSystem.md](SeasonSystem.md)
