# Agent Prompts — Runtime 2D Roguelike (Unity)

Этот каталог содержит готовые **копипаст‑промты** для последовательной реализации 2D real‑time roguelike, где **всё генерируемое в рантайме** создаётся как дочернее под `GodObject`.

## Как пользоваться
- Открывайте `RuntimeRoguelike2D_PromptBook.md`.
- Идите строго по порядку: **P01 → P02 → … → P15**.
- После ядра выбирайте любые опциональные: **O01+**.
- Каждый промт можно отдавать отдельному агенту “как есть”.

## Жёсткие ограничения проекта
- Все C# скрипты: **только** `Assets/_Project/Scripts/` и подпапки.
- Служебные объекты в сцене допустимы (`SceneContext`, `Main Camera`, `Global Light 2D`, `ProjectContext`).
- Всё, что является частью игры и создаётся в рантайме (карта/тайлы/враги/лут/ловушки/UI игры), должно появляться **под `GodObject`**.
