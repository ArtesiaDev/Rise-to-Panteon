# Гильдии

## Формат

Гильдия — **UI-экран с интерфейсом**, не физическая постройка в Лагере. Все улучшения и «постройки» гильдии — элементы интерфейса, прокачиваемые совместно через экран гильдии.

Открывается: **Ярус 3** (через меню).

---

## Функции

| Функция | Описание |
|---------|----------|
| Еженедельный Гильдейский Рейд | Специальный ярус, открытый только для членов гильдии |
| Совместное развитие | Прокачка гильдейских параметров через общий интерфейс |
| Гильдейский рейтинг | Позиция в мировой таблице гильдий |
| Флаг гильдии | Топ-3 гильдии сезона — флаг в Общем Пантеоне |

---

## Рейды

| Тип | Количество |
|-----|-----------|
| Бесплатно | 1 рейд в неделю |
| Премиум-членство | 2 рейда в неделю |

---

## Гильдейское превосходство

- Топ-3 гильдии сезона — флаг гильдии в Пантеоне Героев
- Крупнейшая глубина (максимальный общий ярус гильдии) — публичный рекорд
