# Отложено

> Механики из F2P-концепта «Лагерь Душ» (мобильный мультиплеерный рогалик).
>
> **Не являются частью текущего дизайна и не источник истины.**
> Возможно, вернёмся когда-нибудь — после того как геймплей будет работать так, как задумано. Возможно, никогда.
>
> При возвращении сверять с [GDD](../GDD/README.md): документы опираются на старую структуру
> (линейные ярусы, Лагерь как хаб, Перекрёстки каждые 5 ярусов, рестарт яруса при смерти).

| Документ | Что внутри |
|----------|------------|
| [Monetization.md](Monetization.md) | Косметика, удобство, ускорение, реклама, сезонный пропуск, смягчение смерти (Оберег Души, жетоны возрождения) |
| [Multiplayer.md](Multiplayer.md) | Перекрёстки Глубин, асинхрон (призраки, надписи, могилы других игроков), co-op |
| [ArenaSystem.md](ArenaSystem.md) | PvP-дуэли на Перекрёстках, рейтинг |
| [GuildSystem.md](GuildSystem.md) | Гильдии, рейды |
| [SeasonSystem.md](SeasonSystem.md) | Месячные рейтинговые сезоны с общим seed |
| [SuperioritySystem.md](SuperioritySystem.md) | Титулы, Пантеон Героев, визуальные маркеры статуса |
| [PrestigeSystem.md](PrestigeSystem.md) | Сброс после Стадии 6 ради пассивных бонусов |

Заметки на будущее:
- Престиж можно переродить в одиночный NG+ или связать с режимом «Наследие» — но не как retention-механику.
- Асинхронные следы других игроков (призраки, надписи, могилы) частично перекликаются с хардкор-режимом «Наследие» ([Death.md](../GDD/Death.md)).
