# Разведчики

Ключевой механизм ежедневного возвращения. Открывается с постройкой **Казармы Разведчиков** (Ярус 2).

---

## Принцип работы

Разведчик физически ничего не проходит. Механика — **AFK-генерация наград** с вероятностями, соответствующими выбранному ярусу. Чем выше ярус — тем ценнее лут.

1. Игрок выбирает ярус и отправляет разведчика на **8–12 часов**
2. По умолчанию выбирается последний (наиболее высокий) пройденный ярус
3. После возвращения игрок получает пачку ресурсов

---

## Параметры

| Параметр | Значение |
|----------|----------|
| Бесплатные слоты | 2 |
| Платные слоты (монетизация) | до 6–8 |
| Время возврата | 8–12 часов |
| Ускорение рекламой | −4 часа к времени возврата (3 раза/день) |
| Мгновенный возврат рекламой | 1 разведчик (3 раза/день) |

---

## Выбор яруса

Игрок может отправить разведчика в любой **пройденный** ярус. Ресурсы привязаны к глубине выбранного яруса — всегда есть смысл отправлять в самый высокий.
