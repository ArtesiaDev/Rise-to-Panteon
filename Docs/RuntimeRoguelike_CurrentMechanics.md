## Runtime Roguelike 2D — текущие механики (на данный момент)

Документ описывает **геймплейные механики**, которые уже реализованы в проекте сейчас.  
Технические детали и архитектура намеренно опущены, кроме случаев, когда это влияет на бизнес‑логику (например, **всё создаётся и генерируется в рантайме**).

---

## Общая идея забега

- **Real-time roguelike**: игра идёт в реальном времени (без пошагового режима).
- **Runtime-only контент**: карта, визуал тайлов/сущностей и UI создаются во время запуска забега; готовых контент‑префабов/ассетов для геймплея не требуется.
- **Простая процедурная графика**: пол, стены, игрок, враги, лут и ловушки визуально отличаются (цвет/узор), чтобы их можно было считывать на глаз.
- **Забег детерминируется seed’ом**: при одинаковом seed базовая раскладка карты воспроизводима.

---

## Цикл забега и рестарт

- При старте сцены запускается новый забег:
  - генерируется карта
  - спавнится игрок
  - спавнятся враги
  - поднимается UI
- **Restart**:
  - по клавише **R** (по умолчанию)
  - из HUD кнопкой **Restart**
  - через dev tools (по умолчанию **F5**)
  - рестарт выполняется **без перезагрузки сцены** и с **новым seed**.

---

## Генерация карты

- **Размер карты**: по умолчанию **200×200** клеток.
- **Тип карты**: комнаты + коридоры.
  - На карте создаётся набор комнат случайных размеров (в пределах заданных параметров).
  - Комнаты соединяются коридорами, формируя связную область.
- **Границы карты**: по периметру всегда стены (непроходимые).
- **Старт игрока**:
  - стартовая клетка всегда находится в проходимой области и не заперта стенами.
- **Стартовая зона (safe radius)**:
  - вокруг стартовой клетки гарантируется безопасный радиус:
    - клетки становятся проходимыми
    - в этой зоне **не появляется** лут/враги/ловушки
  - это защищает игрока от “моментальной смерти” на старте.

---

## Передвижение и коллизии

- **Управление**: WASD или стрелки.
- **Движение по сетке**:
  - перемещение только по 4 направлениям (вверх/вниз/влево/вправо)
  - диагонального перемещения нет
  - движение выглядит плавно (переход к центру следующей клетки).
- **Камера**:
  - камера следует за игроком во время движения.
- **Непроходимые клетки**:
  - стены блокируют передвижение.
- **Занятость клеток (occupancy)**:
  - одна клетка не может быть занята несколькими сущностями одновременно
  - это влияет на:
    - спавн врагов
    - перемещение игрока и врагов.

---

## Игрок: характеристики и состояния

- **HP**: у игрока есть здоровье (максимум и текущее).
- **Gold**: валюта (пока без трат — только накопление).
- **XP/Level**:
  - игрок получает опыт
  - при накоплении достаточного XP повышает уровень.

Примечание: состояние “поражение/конец забега при смерти игрока” пока не оформлено отдельным экраном/режимом (это зона будущего расширения).

---

## Бой

### Атака игрока

- **Клавиша атаки**: по умолчанию **Space**.
- **Тип атаки**: ближняя атака по области перед игроком.
  - направление атаки определяется **последним направлением движения**.
- **Кулдаун**: атака не спамится; действует перезарядка по времени.
- **Урон**:
  - базовый урон
  - усиливается перками/прокачкой (если выбран перк на урон).

### Атака врагов

- Если враг достаточно близко к игроку, он наносит урон по **кулдауну**.

### Смерть

- Враги умирают при снижении HP до 0:
  - исчезают
  - освобождают занятую клетку (можно проходить/спавнить других).
- Игрок может получать урон от врагов и ловушек.

---

## Враги

### Спавн

- В начале забега появляется пачка врагов (**initial count**).
- Затем враги **доспавниваются по таймеру** до лимита (**max count**).
- Правила размещения:
  - только на проходимых клетках
  - не в safe radius
  - не на занятых клетках.

### Поведение (AI)

- **Aggro**: если игрок достаточно близко (по радиусу агро), враг начинает преследование.
- **Преследование**:
  - враг строит путь по сетке и двигается к игроку
  - путь обновляется не каждый кадр, а с заданным интервалом.
- **Атака**:
  - если враг рядом — атакует по кулдауну.
- **Idle/бродилка**:
  - если игрок далеко — враг иногда делает случайные шаги.

---

## Ловушки и опасные тайлы (hazards)

Ловушки размещаются на карте при генерации (на проходимых клетках, вне safe radius) с заданной вероятностью.

### Spike

- Наносит урон:
  - **сразу при наступании**
  - и затем **периодически**, пока игрок стоит на клетке со spikes.

### Poison

- При наступании накладывает **яд (DoT)**:
  - урон тиками по времени
  - действует ограниченную длительность.

---

## Лут и подбор предметов

- После смерти врага может выпасть лут (шанс выпадения).
- Типы лута:
  - **Gold**: увеличивает золото игрока
  - **XP**: увеличивает опыт игрока
  - **Heal**: лечит игрока.
- Подбор лута:
  - происходит при контакте с предметом (надежный подбор “в касание”).

---

## Прокачка и перки

- Игрок получает **XP** (в основном через лут) и повышает уровень.
- При **level-up** появляется окно выбора перка:
  - показывается несколько вариантов (по умолчанию 3)
  - варианты выбираются случайно из списка доступных перков.
- Перки (минимальный набор):
  - **+Max HP**
  - **+Damage**
  - **+Move Speed**.

Примечание: выбор перка сейчас происходит в real-time (мир не ставится на паузу автоматически).

---

## Баланс и рост сложности (Difficulty)

- Сложность растёт:
  - **со временем** с начала забега
  - и дополнительно зависит от **уровня игрока**.
- Эффекты роста сложности:
  - увеличиваются боевые характеристики врагов (в первую очередь здоровье; также усиливается урон)
  - враги могут появляться чаще (ускорение доспавна).

---

## HUD (интерфейс в игре)

На экране отображаются:
- **HP** игрока
- **XP и прогресс до следующего уровня**
- **Level**
- **Gold**
- **Seed**
- кнопка **Restart**.

---

## Debug / DevTools (для тестирования)

DevTools можно включать/выключать настройкой.

Доступные действия (дефолтные хоткеи):
- **F5** — restart забега
- **G** — переключить отладочные gizmos
- **T** — телепорт игрока в клетку под курсором (только если клетка проходимая и не занята).

Отладочный вывод на экране:
- seed
- координаты клетки игрока
- текущее количество врагов
- текущее количество предметов лута на карте.
