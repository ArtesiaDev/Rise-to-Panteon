# Миникарта

## Обзор

UI-оверлей миникарты показывает исследованную часть подземелья с маркерами сущностей.
Реализована через Runtime Texture2D (1 пиксель = 1 клетка карты).

## Функциональность

- **Отображение карты**: исследованные области — бежевым, видимые — ярче, стены — темнее.
- **Маркеры**: игрок — зелёная точка, враги в поле зрения — красные точки.
- **Toggle**: клавиша Tab (включить/выключить оверлей).
- **Обновление**: только при изменении позиции игрока (через FogRenderRequest).

## Цвета

| Элемент | Цвет |
|---------|------|
| Unexplored | Прозрачный |
| Explored (пол) | Тёмно-бежевый |
| Visible (пол) | Бежевый |
| Стены | Тёмно-коричневый |
| Игрок | Зелёный |
| Враги (Visible) | Красный |

## Управление

- **Tab** — toggle миникарты (или M как альтернатива).
- При первом открытии видна только стартовая комната (если туман войны включён).

## Реализация

- **Hybrid мост**: `MinimapBridge` (MonoBehaviour, Hybrid/UI/)
- **Текстура**: `Texture2D` (MapSize.x × MapSize.y, RGBA32, FilterMode.Point)
- **UI**: `RawImage` компонент для отображения
- **Toggle**: `MinimapToggleTag` (IComponentData, IEnableableComponent) через InputBridge
- **Данные**: читает `NativeArray<FogState>` из FogOfWarSystem + MapBlob + GridPosition
