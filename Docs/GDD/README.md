## Одной фразой

2D RPG-песочница. Искра — ничтожный сгусток жизненной силы — поглощает обитателей измерений,
эволюционирует в то, что сама выбрала и поглотила, и поднимается сквозь иерархию измерений к Пантеону.
Мир живой, помнит поступки игрока и не ведёт за руку.

## Ключевое ощущение

- **Свобода** — идти куда угодно, решать как угодно, становиться кем угодно.
- **Первооткрыватель** — исследуешь неизвестный мир, который никто не объясняет.
- **Влияние** — твои действия надолго меняют мир.
- **Реиграбельность** — хочется начать заново: другой мир, другая эволюция, другая история.

## Цель игры

Дойти до Пантеона и стать богом. Концовок несколько: какая будет — зависит от того, кем игрок стал
и что сделал по пути. После финала можно остаться в мире.

Первый релиз — глава 1: она завершается Первым Рубежом со своими финалами ([Scope.md](Scope.md)).

## Основная петля

```text
исследуй → охоться и поглощай → эволюционируй → поднимайся туда, где плотнее
    ↑                                                        │
    └──── мир реагирует: экосистема, фракции, соперники ─────┘
```

[Лагерь](Camp.md) — личная база рядом с петлёй, а не её обязательный центр.

## Столпы

### 1. Один закон для всех
Жизненную силу поглощает не только игрок. Монстры, NPC, другие восходящие живут по тому же правилу:
охотятся, растут; распад и давление действуют на всех. Мини-босс — не скрипт, а существо,
которое поглотило достаточно других. Мир — экосистема, а не декорация.

### 2. Ты — то, что поглотил
Путь эволюции складывается из выборов игрока и из того, чью силу он впитал, — а не из выбора класса в меню.
Максимум разнообразия.

### 3. Мир помнит
Мир генерируется один раз на сохранение и хранит последствия: убитый Страж не воскресает,
выжатая зона беднеет, фракция помнит предательство. Отката нет — только автосохранение.

### 4. Неизвестность
Никаких маркеров заданий и объяснений. Лор — из надписей, находок и разговоров.
Барьеры мягкие — кроме порога Врат Резонанса, так велит лор.
У любой преграды несколько решений: убить, обойти, договориться, обмануть.
**Каждое небоевое решение даёт то, чего не даёт убийство**: репутацию, NPC для Лагеря, знание, доступ,
дань или материалы.

### ⚠️ Правило читаемости мира
Игрок всегда понимает, **что** изменилось в мире и **почему** — через следы в мире и слухи,
ненавязчиво, без объяснения каждого события. Симуляция, которую игрок не замечает, не нужна.
Подробно — [LivingWorld.md](LivingWorld.md).

## Рамки проекта

| Решение | Суть |
|---------|------|
| Режим | Одиночная игра. Мультиплеер не проектируем (отложен) |
| Приоритет | Сначала геймплей. Монетизация — не сейчас, возможно никогда |
| Разработка | Соло → объём держим под контролем |
| Платформа | Не фиксируем. Ориентир: мобильные + ПК. Экран альбомный; управление помещается на тач-экран |
| Графика | 2D, заранее подготовленные ассеты, собственный стиль (разрабатывается отдельно) |
| Контент | Процедурные подземелья + фиксированные ключевые точки ([World.md](World.md)) |
| Лор | Не меняется; дополнения — только с согласия автора ([Lore.md](Lore.md)) |

## От чего отказались

| Было | Почему |
|------|--------|
| Генерация карты, визуала и UI в рантайме с пустой сцены | Ошибочная идея: делаем обычную игру с готовыми ассетами |
| Линейная стопка этажей, рестарт яруса при смерти | Противоречит открытому миру и столпу «Мир помнит» |
| Жёсткие барьеры между этажами | Заменены мягкими — через плотность |
| Фиксированное дерево классов | Заменено эволюцией от поглощённого |
| F2P-механики, сезоны, PvP, гильдии, AFK-разведчики | Отложены в [Parked](../Parked/README.md) |
