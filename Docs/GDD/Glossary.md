## Мир

| Термин | Значение |
|--------|----------|
| Башня | Иерархия измерений целиком |
| Ярус | Одно измерение: свой биом, экосистема, правила. Номер яруса — глубина в Башне |
| Этаж | Полоса плотности внутри яруса — одна непрерывная карта из локаций, соединённых перевалами; загрузок внутри этажа нет (`W01`). Выше этаж — плотнее среда |
| Локация | Часть этажа из нескольких угодий: единица экосистемы и симуляции — своя плотность, популяции, гнёзда, часы (`W01`, `W02`) |
| Тип локации | Экологический облик локации: пастбищная, гнездовая, охотничья, руинная, опасная. Задаёт состав угодий, точек интереса и элементы фона; этаж смешивает несколько типов (`W01`, `W02`) |
| Угодье | Участок локации со своей ролью в экосистеме: пастбище, гнездовье, логово, тропа-засада, укрытия (`W02` R37); якорь, Врата и ручные вставки встраиваются как особые угодья. Угодья связаны тропами (`W02`) |
| Перевал | Проход между соседними локациями этажа, без загрузки; существа его не пересекают. У локации не меньше двух (`W16`). Характер: **тихий** — просто путь; **застава** — гнездо территориального вида или логово мини-босса; **печать** — запертый проход (`W12`); **опасный** — ловушки или эффекты среды; **тайный** — скрытое место на границе локаций (`W15`). Граница — **линия перевала**: бой через неё не идёт (`W16` R17) |
| Пустота | Непроходимое пространство вне угодий и троп, видное насквозь; работает как пропасть: снаряды и удары над ней летят, рывок и перелёт её не пересекают (`W02` R9, `W11` R26). Провал тропы тела — не пустота: его пересекает перелёт (`W15`, `C04`) |
| Развёрнутая локация, развёртка | Развёрнутая локация живёт в реальном времени: текущая, где стоит игрок, и соседняя, к перевалу которой он подходит. Развёртка — догон соседней локации и превращение её чисел в существ заранее, без экрана загрузки; игрок отошёл от перевала — соседняя сворачивается (`W16` R21) |
| Грамматика этажа | Правила формы угодий, троп и границ этажа, заданные его телесностью: от архипелага островков Бездны до прямоугольных склепов верха Катакомб (`W11`; параметры генератора — `W02`) |
| Материальность этажа | Параметр грамматики этажа 0…1: округлость форм, шум края, ширина и прямота троп, доля сплошных стен. Этаж 1 Бездны — 0, этаж 4 Катакомб — 1 (`W11`) |
| Эталонная планировка | Одобренная автором и доведённая вручную планировка этажа Среза: одна во всех мирах, seed задаёт только наполнение (`W02` R38, R39) |
| Генератор вариаций | Генератор новых планировок этажа из seed по грамматике этажа и шаблонам, нарезанным из эталонов; делается до производства ярусов 2–10 (`W02` R40, R41) |
| Длина яруса | Число этажей в нём |
| Плотность среды | Постоянная характеристика локации, лежит в полосе своего этажа. От неё считаются распад и давление (`W05`) |
| Телесность | Насколько материально тело существа, персонажа, вещи или само место; задаётся плотностью по одному закону для всех ([Lore.md](Lore.md) → «Плотность и телесность»). Пять степеней совпадают с полосами стадий (`E07`; полосы — `E02` §5): **бесплотные** (Искра) — сгущения стихии без формы; **оформленные** (Сгусток) — энергия держит форму, плоти нет; **полуплотные** (Тень) — энергия частями прорастает материей; **плотные** (Облик, Высший облик) — плоть; **божественные** (Полубог, Бог) — выше плоти: мифические существа божественного ранга, после главы 1. «Искра» и «Сгусток» — только имена стадий; облики существ — огонёк, всполох, вихорёк, капля, сгущение |
| Запас жизненной силы | Истощаемая величина локации: от него зависят популяции и восстановление. Плотность среды не меняет (`L04`) |
| Единица силы | Сила одной рядовой особи среднего размера; мера запаса жизненной силы и её оборота («поток силы» — только визуал поглощения) |
| Ступень истощения | Насколько выжата локация (0–3); задаёт следы и численность (`L04`) |
| Ёмкость | Предел популяции вида в локации; прирост сверх него уходит мигрантами (`L04` R21) |
| Врата Резонанса | Переход в следующий ярус. **Главные** — одни на ярус, с изначальным Стражем. **Малые** — необязательные, тайные, со Стражами-преемниками (`W09`) |
| Состояния Врат | **Молчат** (нет резонанса) · **гудят** (резонанс есть, Страж не пройден) · **открыты** |
| Нижняя сторона Врат | Место, куда Врата выводят в следующем ярусе; от неё считается плотность этажа 1 этого яруса |
| Комплекс Врат | Ручная вставка на верхнем этаже, одна на ярус: арена изначального Стража, преддверие с якорем у Врат, зал Врат |
| Порог Врат | Плотность, нужная для резонанса с Вратами. Без неё Врата не открываются — единственный жёсткий барьер. Не путать с порогом стадии и порогом оси |
| Рубеж | Ярус с мегабоссом; завершает главу |
| Цитадель | Ручная часть Рубежа, где живёт мегабосс |
| Цикл перестройки | Период, за который локации Теневого Разлома переключаются между заранее построенными вариантами (`W19`) |
| Ручная вставка | Заранее сделанное особое угодье или группа угодий, которую генератор встраивает в процедурный мир (`W04`) |
| Скрытое место | Карман за закрытым входом с приметой. Открывают его способы пробить, пройти сквозь, напитать, давление; тропу тела — ещё способ семейства, ключ к миру оси и Кладоискательство. Внутри одно: тайник, заповедный карман, короткий путь (срезка между угодьями), останки восходящего, тихий карман (место для кокона без хозяев) или секретная сюжетная комната (`W15`) |
| Тайник | Содержимое скрытого места: вместилище с добычей (`W15`) |
| Заповедный карман | Содержимое скрытого места: богатая точка кормёжки и особь, уровень которой на 2 выше сородичей (`W15`) |
| Примета | Признак скрытого места; своя у каждого способа открыть: трещина, недопроявленная стена, голодная печать, «глубокая» трещина; у троп тела — пролом, щель, провал, завеса. Видна любому, кроме незримой: её видит только кладоискатель (`W15`) |
| Недопроявленная стена | Примета способа «пройти сквозь» (Бездна, этажи 1–2 Катакомб): выглядит стеной, мерцает и проходима; первый проход проявляет её в открытый проход (`W15`) |
| Голодная печать | Примета способа «напитать»: открывается, когда в её радиусе гибнет существо (`W15`). Не путать с печатью-замком (`W12`) |
| Тропа тела | Скрытое место под способ семейства тела: **пролом** — таран твёрдых, **щель** — просачивание текучих, **провал** до 2 клеток — перелёт летучих, **завеса** — фаза призрачных. У каждой ещё два ключа: ключ к миру своей оси и Кладоискательство (`W15`) |
| Останки восходящего | Место павшего восходящего: угасшая оболочка или погребение, его надпись и контейнер с его вещью (`W14`, `N01`). Не след |
| Всплеск силы | Временное переполнение точки кормёжки по часам мира: свечение и гул, существа локации сходятся к ней, поглощение у всплеска даёт прибавку (`W20`) |
| Эффект среды | Огонь, яд, вода и т. п. на клетках сетки локации; одинаков для всех (`W17`) |
| Гнездо | Угодье-дом популяции вида в локации, одно на вид: гнездовье, у охотников — логово, у территориального вида — иногда застава у перевала. Там вид размножается, раненые отдыхают (`B01` R13, `B02`). Не путать с гнездом насыщения на вещи |
| Разорённое гнездо | Гнездо, разрушенное действием «разорить»; вид больше не размножается в этом угодье (`L13`) |
| Якорь | Точка отдыха, возрождения и связи мира с Лагерем: стартовый, у Врат, обычный (`K02`) |
| Занятый, заблокированный якорь | Занятый — обычный якорь с гнездом, логовом или святыней до пробуждения. Заблокированный — пробуждённый, перекрытый миром вдали. Какие якоря не блокируются — `K02` |
| Шаг мира | Пересчёт мира вдали от игрока; идёт подшагами. У каждой локации свои часы |
| Время мира | Часы мира: идут по прогрессу игрока — поглощённой силе в долях стоимости уровня — и долям шага (`L01` R2, R18) |
| Единица времени мира | Мера часов мира: стоимость уровня, к которому копится опыт |
| Событие шага | Событие, которое применяет накопленный шаг; перечень — `L01` R5 |
| Накопленный шаг | Время мира, накопленное и ещё не применённое; событие шага применяет его целиком и обнуляет |
| Минимальный шаг | Нижняя граница шага у кокона и смерти (`L01` R6) |
| Доля шага | Фиксированная прибавка к накопленному шагу за небоевое решение с наградой или проход изначального Стража (`L01` R18) |
| Небоевое решение с наградой | Исход из закрытого перечня `N02` |
| Догон, подшаг | Догон — применение шага к локации от её часов до «сейчас»; подшаг — его единица (`L01` R9, §5) |
| Запись изменений | Видимые изменения локации с последнего визита игрока; по ней при входе расставляются следы |
| Предыстория (мира) | Детерминированный прогон шага мира при создании мира (и при достройке) до начала отсчёта (`L03` R38). Не путать с предысторией NPC |
| Seed | Зерно генерации мира — наполнение: расселение, содержимое находок, тексты надписей; в вариациях — и планировка (`W02` R39, R40). Тот же seed при той же версии сборки — тот же стартовый мир |
| Миграция | Уход части популяции в соседнюю локацию своего яруса шагом мира (`L02` R12) |
| Страховка | Граница, за которую мир не заходит; ограничивает мир, а не игрока. Перечень — `L12` |
| Журнал событий симуляции | Единый внутренний журнал значимых событий мира: источник слухов и толкований Хроники; следы строятся по записи изменений. Не путать с журналом игрока |
| Класс события | Значимость события для слухов: А — крупное, Б — заметное, В — фон (`L06`) |
| Последнее увиденное | Состояние места, каким персонаж видел его в последний раз: так его показывают карта и раздел журнала «Знакомые» (`U05` R8) |
| Переход | Парный проход между этажами — вверх или вниз: объект у края локации, с загрузкой (`W16`). Внутри этажа локации соединяют перевалы; Врата — отдельно |
| Зона перехода | Проём перехода между этажами или Врат: игрок в нём недосягаем для существ. У перевала её нет — там линия перевала: за ней игрок недосягаем для существ этой стороны (`W16` R11) |
| Зона прибытия | Место у точки входа перехода между этажами и Врат без существ, ловушек, примет и постоянных эффектов среды (`W16` R14) |
| Снимок мира | Полное сохранение мира; когда пишется — `M01` R15, R18 |
| Ключ | Не предмет, а счётчик «ключи этой локации»: один ключ — одна печать своей локации (`W12` R11); ключ печати перевала — обеих его локаций (`W12` R22). Не путать с ключом к миру |
| Печать | Запертый проход на перевале или на входе в угодье: непроходим для всех, пока не открыт; как открыть — `W12`. Выбитая печать — отдельное состояние. Не путать с голодной печатью (`W15`) |
| Сокровищница | Угодье за печатью с контейнерами, хотя бы в одном — предмет (`W14` R7, `W12` R19) |
| Ступень деградации | 0–3 — насколько локацию разрушило давление: трещины, сколы, поваленный декор (`W07`). Не путать со ступенью истощения — её след выцветание |
| След | Видимое в мире последствие события |
| Слух | Сообщение о значимом событии, у которого есть след: реплика NPC, реакция персонажа, запись в журнале (`L06`) |

## Персонаж

| Термин | Значение |
|--------|----------|
| Плотность (персонажа) | Сила персонажа. Измеряется в уровнях |
| Действующая плотность | Плотность с учётом приглушения: меньшая из истинной и плотности среды |
| Разрыв | Разница плотностей в уровнях. «Разрыв в стадию» — не меньше ширины стадии более слабой стороны (локации или жертвы) |
| Уровень | Ступень плотности. Даёт два очка Круга и допуск по плотности к метаморфозе, Вратам и вещам; характеристик не даёт (`E02`) |
| Опыт | Прогресс к следующему уровню |
| Стадия | Ступень воплощения — группа уровней: Искра, Сгусток, Тень, Облик, Высший облик, Полубог, Бог; телесность стадий и что открывает метаморфоза — `E07`. Имя стадии пишется с заглавной: «стадия Облик» — не «облик» |
| Порог стадии | Уровень, на котором стоит метаморфоза: дальше уровень не растёт до её завершения |
| Предел главы | Порог последней стадии главы: выше уровень в этой главе не растёт (`E02` §5; порог Врат Рубежа — `W09` §5) |
| Ширина стадии | Число уровней в стадии (`E02` §5). Мера «разрыва в стадию» |
| Метаморфоза | Смена стадии в коконе: игрок выбирает следующее тело по древу тел; открывает слоты приёмов и вещей и полностью лечит (`E07`) |
| Кокон | Уязвимое состояние на время метаморфозы; место — Лагерь или мир (`E08`) |
| Оболочка кокона | След кокона: пустая — после успеха, приманка для хищников; разорванная — после разрушения, только след (`E08`) |
| Малое здоровье | Граница здоровья, на которой ломается кокон (`E08` §5) |
| Индикатор готовности | Элемент HUD «метаморфоза готова» (`E08`, `U03`) |
| Тело | Воплощение персонажа на стадии — одно из 34 тел древа. Даёт способ семейства и прибавку тела; новых приёмов не даёт (`E13`) |
| Древо тел | Тела по стадиям: из Искры ведут три Сгустка, из каждого следующего тела — две формы следующей стадии; на метаморфозе игрок выбирает одну (`E13`) |
| Семейство тела | Твёрдые, текучие, летучие или призрачные — как состояния вещества. Задаёт облик тела, способ семейства и характеристики прибавок (`E13`) |
| Способ семейства | Рывок семейства — таран, просачивание, перелёт или фаза, у Искры — вспышка (`C04`) — и тропы тела, которые он открывает (`W15`) |
| Прибавка тела | Шаги по 10% к характеристикам семейства, которые даёт тело; прибавки всех пройденных тел складываются (`E13`) |
| Облик | Внешний вид тела существа или персонажа; у персонажа его задают семейство и стадия (`E13`). Не путать со стадией Облик |
| Ореол | Свечение тела; цвет — от отпечатка стихий (`E01`). Поведение — `W05` R6, `W08`, `C08` |
| Поглощение | Получение опыта, лечения и отпечатка стихии вида из тела существа (`E01`) |
| Скудная добыча | Меньше опыта от жертвы слабее; кривая — `E01` |
| Отпечаток стихий | След поглощённого: копится по шести стихиям от стихии вида, красит ореол, вызывает реплики, тратится только ремеслом Насыщение. Ничего не открывает и не закрывает (`E01`) |
| Поток силы | Визуал автопоглощения: сила летит от тела к игроку |
| Круг | Девять осей развития по кругу; очки Круга игрок вкладывает в любые оси (`E14`) |
| Ось | Направление Круга: Стойкость, Ближний бой, Дальний бой, Ловкость, Скрытность, Слово, Власть, Магия, Внутренняя энергия. Ранг оси растит две её характеристики (`E14`) |
| Очко Круга | Единица вложения в ось: одно очко — один ранг; два очка за уровень (`E02`, `E14`) |
| Ранг | Ступень оси Круга (0–100, `E14`) или ремесла (1–10, `E16`) |
| Основа оси | Приём без выбора, который даёт ранг 1 оси (`E14`) |
| Порог оси | Ранг оси, на котором игрок выбирает новый приём из 2–3 (`E14`). Не путать с порогом стадии и порогом Врат |
| Ключ к миру | Способ оси решать преграды без боя; открывается на ранге 20 (`E14`) |
| Слава | Ответ мира на развитые оси: реплики, цены, страх, просьбы (`E14`) |
| Обет | Выбор одной из двух веток оси на ранге 50; выше 50 растут только оси с обетом (`E15`) |
| Ветка обета | Сторона оси, обращённая к одному из двух соседей по Кругу; выбор закрывает вторую (`E15`) |
