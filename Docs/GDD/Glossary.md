# Глоссарий

> Один термин — одно значение. Здесь — что это; правила — в файле фичи по ссылке. Новый термин сначала добавляется
> сюда, потом используется в других документах.

## Мир

| Термин | Значение |
|--------|----------|
| Башня | Иерархия измерений целиком |
| Ярус | Одно измерение: свой биом, экосистема, правила. Номер яруса — глубина в Башне |
| Этаж | Полоса плотности внутри яруса. Выше этаж — плотнее среда |
| Локация | Связная часть этажа из нескольких комнат. Единица загрузки и симуляции |
| Длина яруса | Число этажей в нём |
| Плотность среды | Постоянная характеристика локации, лежит в полосе своего этажа. От неё считаются распад и давление (`W05`) |
| Запас жизненной силы | Истощаемая величина локации: от него зависят популяции и восстановление. Плотность среды не меняет (`L04`) |
| Единица силы | Сила одной рядовой особи среднего размера; мера запаса жизненной силы и её оборота («поток силы» — только визуал поглощения) |
| Ступень истощения | Насколько выжата локация (0–3); задаёт следы и численность (`L04`) |
| Ёмкость | Предел популяции вида в локации; прирост сверх него уходит мигрантами (`L04` R21) |
| Врата Резонанса | Переход в следующий ярус. **Главные** — одни на ярус, с изначальным Стражем. **Малые** — необязательные, тайные, со Стражами-преемниками (`W09`) |
| Состояния Врат | **Молчат** (нет резонанса) · **гудят** (резонанс есть, Страж не пройден) · **открыты** |
| Нижняя сторона Врат | Место, куда Врата выводят в следующем ярусе; от неё считается плотность этажа 1 этого яруса |
| Комплекс Врат | Ручная вставка на верхнем этаже, одна на ярус: арена изначального Стража, преддверие с якорем у Врат, зал Врат |
| Порог | Плотность, нужная для резонанса с Вратами. Без неё Врата не открываются — единственный жёсткий барьер |
| Рубеж | Ярус с мегабоссом; завершает главу |
| Цитадель | Ручная часть Рубежа, где живёт мегабосс |
| Цикл перестройки | Период, за который локации Теневого Разлома переключаются между заранее построенными вариантами (`W19`) |
| Ручная вставка | Заранее сделанная комната или группа комнат, которую генератор ставит в процедурный мир |
| Тайник | Скрытое вместилище с добычей за стеной; открывается разрушением его приметы (`W15`) |
| Тайный ход | Скрытый проход внутри локации (обход, срезка) или между локациями (дополнительное ребро графа); не входит в обязательные маршруты |
| Примета | Видимый признак тайника или тайного хода (трещина и т. п.) |
| Эффект среды | Огонь, яд, вода и т. п. на клетках тайловой сетки; одинаков для всех (`W17`) |
| Гнездо | Комната-дом популяции вида в локации, одно на вид: там вид размножается, раненые отдыхают (`B02`) |
| Очищенное гнездо | Гнездо без хозяев в комнате при живом виде в локации — место кокона с бонусом (`E09`) |
| Разорённое гнездо | Гнездо, разрушенное действием «разорить»; вид больше не размножается в этой комнате (`L13`) |
| Якорь | Точка отдыха, возрождения и связи мира с Лагерем: стартовый, у Врат, обычный (`K02`) |
| Занятый, заблокированный якорь | Занятый — обычный якорь с гнездом, логовом или святыней до пробуждения. Заблокированный — пробуждённый, перекрытый миром вдали. Какие якоря не блокируются — `K02` |
| Шаг мира | Пересчёт мира вдали от игрока; идёт подшагами. У каждой локации свои часы |
| Время мира | Часы мира: идут по прогрессу игрока — поглощённой силе в долях стоимости уровня — и долям шага (`L01` R2, R18) |
| Единица времени мира | Мера часов мира: стоимость уровня, к которому копится опыт |
| Событие шага | Событие, которое применяет накопленный шаг; перечень — `L01` R5 |
| Накопленный шаг | Время мира, накопленное и ещё не применённое; событие шага применяет его целиком и обнуляет |
| Минимальный шаг | Нижняя граница шага у кокона и смерти (`L01` R6) |
| Доля шага | Фиксированная прибавка к накопленному шагу за небоевое решение с наградой или проход изначального Стража (`L01` R18) |
| Небоевое решение с наградой | Исход из закрытого перечня `N02` R23 |
| Догон, подшаг | Догон — применение шага к локации от её часов до «сейчас»; подшаг — его единица (`L01` R9, §5) |
| Запись изменений | Видимые изменения локации с последнего визита игрока; по ней при входе расставляются следы |
| Предыстория (мира) | Детерминированный прогон шага мира при создании мира (и при достройке) до начала отсчёта (`L03` R38). Не путать с предысторией NPC |
| Seed | Зерно генерации мира: планировка, расселение, содержимое находок. Тот же seed при той же версии генератора — тот же стартовый мир |
| Соль мира | Время создания мира; входит в зерно вариантов эволюции: планировка общая по seed, варианты линек — нет |
| Миграция | Уход части популяции в соседнюю локацию своего яруса шагом мира (`L02` R12) |
| Страховка | Граница, за которую мир не заходит; ограничивает мир, а не игрока. Перечень — `L12` |
| Журнал событий симуляции | Единый внутренний журнал значимых событий мира: источник слухов и толкований Хроники; следы строятся по записи изменений. Не путать с журналом игрока |
| Класс события | Значимость события для слухов: А — крупное, Б — заметное, В — фон (`L06`) |
| Последнее увиденное | Состояние места, каким персонаж видел его в последний раз: так его показывают карта и раздел журнала «Знакомые» (`U05` R8) |
| Переход | Парный проход между локациями: на этаже — отрезок общей границы; вверх и вниз — объект у края локации. Врата — отдельно |
| Зона перехода | Проём перехода: игрок в нём недосягаем для существ (`W16`) |
| Снимок мира | Полное сохранение мира; когда пишется — `M01` R15, R18 |
| Ключ | Не предмет, а счётчик «ключи этой локации»: один ключ — одна дверь своей локации (`W12` R11) |
| Запертая дверь | Дверь, непроходимая для всех, пока не открыта; как открыть — `W12`. Выбитая дверь — отдельное состояние |
| Сокровищница | Комната за запертой дверью с контейнерами, хотя бы в одном — предмет (`W14` R7, `W12` R19) |
| Ступень деградации | 0–3 — насколько локацию разрушило давление: трещины, сколы, поваленный декор (`W07`). Не путать со ступенью истощения — её след выцветание |
| След | Видимое в мире последствие события |
| Слух | Сообщение о значимом событии, у которого есть след: реплика NPC, реакция персонажа, запись в журнале (`L06`) |

## Персонаж

| Термин | Значение |
|--------|----------|
| Плотность (персонажа) | Сила персонажа. Измеряется в уровнях |
| Действующая плотность | Плотность с учётом приглушения: меньшая из истинной и плотности среды |
| Разрыв | Разница плотностей в уровнях. «Разрыв в стадию» — не меньше ширины стадии более слабой стороны (локации или жертвы) |
| Порог стадии | Уровень, на котором стоит метаморфоза: дальше уровень не растёт до её завершения |
| Предел главы | Порог последней стадии главы: выше уровень в этой главе не растёт (`E02` §5; порог Врат Рубежа — `W09` §5) |
| Ширина стадии | Число уровней в стадии (`E02` §5). Мера «разрыва в стадию» |
| Уровень | Ступень плотности. Даёт очки характеристик и базовый рост здоровья и урона |
| Характеристики | Мощь (Воин), Воля (Маг), Ловкость (Следопыт), Тлен (Некромант) — рабочие названия. Из них выводятся здоровье, урон и т. д. |
| Закреплённая добыча | Предметы, закреплённые отдыхом у якоря или унесённые через него в Лагерь; незакреплённые при смерти уходят в Эхо (`D01` R5, R12) |
| Опыт | Прогресс к следующему уровню |
| Стадия | Группа уровней; степень воплощения (Искра … Вознесённый) |
| Поглощение | Получение плотности и эссенции из существа |
| Эссенция | Качество поглощённого вида. Эссенции объединены в семейства |
| Семейство | Группа эссенций родственных видов: общие базовое тело и сменные части, цвет облика, вес по полюсам. Семейства по этапам — `E04` |
| Кость (семейство) | Семейство Катакомб, полюс Некромант (`E04` R18, `C06` R22). Не путать с материалом кость (`I09`) |
| Камень (семейство) | Семейство Катакомб, полюс Воин (`E04`, `B01`). Не путать с якорным камнем Лагеря |
| Состав | Накопленные эссенции персонажа |
| Тяготение к полюсам | Близость облика к полюсам — 4 полосы; считается только из состава (`E04` R9) |
| Скудная добыча | Меньше опыта и эссенции от жертвы слабее; кривая — `E01` R4 |
| Черта | Единица облика. Типы: активная способность, модификатор атаки, усиление, сменная часть тела. У черты есть ранги |
| Лимит черт | Сколько черт несёт облик; растёт с каждой метаморфозой |
| Слот способности, набор | Ячейка для активной черты — одна кнопка; расстановка по слотам — набор. Число слотов — `C05` R2, замена — `C05` R5 |
| «В запасе» | Активная черта без слота: не действует, пока не займёт слот |
| Базовая атака | Атака тела на отдельной кнопке; тип и свойства по стадиям — `C03` |
| Источники вариантов | И1 — доминирующая эссенция, И2 — недавняя или редкая, И3 — рост ранга, И4 — сдвиг к полюсу (`E06`) |
| Отложенная линька | Линька, которую игрок не запустил; правила — `E08` R4, `E02` R6, R8 |
| Оболочка кокона | След кокона: пустая — после успеха, приманка для хищников; разорванная — после разрушения, только след (`E08`) |
| Ореол | Свечение облика; цвет — от доминирующего семейства. Поведение — `W05` R6, `W08`, `C08` |
| Статус, тип урона | Статус — эффект попадания на время (горение, отравление, замедление, проклятие); это не распад. Тип урона — вид урона, выводится из семейств; «физический» — один из них (`C06`) |
| Номер поколения | Счётчик Искр мира в «Наследии»; входит в зерно вариантов |
| Поток силы | Визуал автопоглощения: сила летит от тела к игроку |
| Облик | Совокупность черт персонажа |
| Форма | Облик стадии 3+ как узнаваемый архетип (Берсерк, Пиромант…) |
| Полюс | Одна из четырёх осей пространства обликов: Воин, Маг, Следопыт, Некромант |
| Линька | Малая эволюция: новые черты |
| Метаморфоза | Большая эволюция: смена стадии |
| Кокон | Уязвимое состояние во время линьки или метаморфозы |
| Номер эволюции | Общий счётчик линек и метаморфоз — входит в зерно вариантов |
| Рост ранга | Источник вариантов эволюции: усиление уже имеющейся черты |
| Перерастание | Замена черты на черту нового доминирующего вида на линьке (`E11`) |
| Эволюционная услуга | Платная услуга Летописца: переброс вариантов, перераспределение очков (`E12`) |
| Призванный | Существо, поднятое игроком из останков (полюс Некромант, `C09`) |
| Малое здоровье | Граница здоровья, на которой ломается кокон (`E08` §5) |
| В бою | Один флаг для всех систем; условие — `C01` R21 |
| Распад | Воздействие среды плотнее персонажа: сначала ослабление, при большем разрыве — потеря здоровья. Не урон и не статус (`W06`) |
| Давление | Воздействие персонажа на среду слабее его — с разрыва в стадию локации (`W07`) |
| Волна страха | Всплеск страха при снятии приглушения, если оно держалось не меньше N секунд: пугает всё слабое рядом (`W08`) |
| Страх | Реакция существ и NPC на давление (`W07`, `B02`). Не путать с устрашением (шкалой фракции) |
| Приглушение | Переключатель, при котором действующая плотность — меньшая из истинной и плотности среды (`W08`) |
| Метка опасности | Цвет и форма у существа — ступень разрыва между ним и действующей плотностью персонажа (`U03` R17) |
| Индикатор готовности | Элемент HUD: «линька готова» или «метаморфоза готова» |
| Реакция персонажа | Одна строка-мысль персонажа над ним, без паузы (`N05`). «Реплика» — её текст |
| Медленный шаг | Скрытное движение (`C08`) |

## Существа и NPC

| Термин | Значение |
|--------|----------|
| Вид | Тип существ с общей эссенцией, поведением и внешностью |
| Популяция | Численность вида в локации — так мир хранит существ вдали от игрока |
| Трофический уровень | Место вида в пищевой сети: Т0 пасутся у точек кормёжки, Т1 — падальщики, Т2 — хищники, Т3 — вершинные хищники. Смещает уровень особи (`W05` R4, §5) |
| Точка кормёжки | Место пастьбы нижнего уровня пищевой сети |
| Приём | Уникальное действие вида; становится кандидатом черты, если такая черта есть в каталоге (`B01`, `E04` R12) |
| Рядовое существо | Не мини-босс, не Страж, не соперник |
| Поимённое существо | Существо, которое мир хранит отдельно, а не числом популяции: мини-босс, Страж, носитель Эха, соперник, NPC |
| Приманка | То, чем игрок отвлекает существ: тело, пустая оболочка кокона, Эхо |
| Ослабленное существо | Существо с малым остатком здоровья, которое уходит в гнездо восстанавливаться (`B02` R21). Не путать с фазой ослабления распада |
| Логово | Гнездо, в котором живёт мини-босс |
| Мини-босс | Особь вида, выросшая от поглощения. Ведётся поимённо |
| Ступень роста | «Эволюция» существа внутри вида: размер, эффекты, части (`B03`) |
| Страж Порога | Роль у Врат. **Изначальный** — уникальный, ручной работы. **Преемник** — занявший место убитого: возвышенное или зарождённое существо с шаблоном Стража либо соперник |
| Место Стража | Роль у главных Врат, которая не пустует: убитого сменяет преемник (`B05` R1, R22) |
| Возвышение, зарождение | Как мир назначает преемника: возвышение — мини-босс этажа Врат получает шаблон Стража; зарождение — если мини-босса нет, Врата создают Стража из особи сильнейшего вида этажа. Не путать со стадией «Вознесённый» |
| Шаблон Стража | Общие данные роли поверх любого вида: фазы, механики арены, поза поклона, титул |
| Проход через Стража | Второй ключ Врат (первый — резонанс): бой или небоевой путь (`W09`, `B04` R6) |
| Небоевой путь | Проход изначального Стража без боя (`B04`) |
| Мегабосс | Изначальный Страж Рубежа; его проход любым путём — финал главы (`B06`). Мегабосс Первого Рубежа — Десятник |
| Десятник | Изначальный Страж Первого Рубежа, мегабосс главы 1 (`B06` §9, [Lore.md](Lore.md)) |
| Сухостой | Изначальный Страж Бездны (Срез): иссохший остов у Врат (`B04` §9) |
| Испытание Вдохом | Небоевой путь Сухостоя (`B04` §9) |
| NPC | Разумное существо, с которым можно говорить; может переехать в Лагерь. Кто такие NPC — [Lore.md](Lore.md) |
| Ключевой NPC | Авторский NPC с авторской просьбой (`L07`) |
| Встреча | Момент, снимающий защиту «до встречи»: для NPC — первый разговор, для изначального Стража и авторской вставки — первое появление в поле зрения |
| Видимая угроза | Угроза NPC со следом и слухом: разрастающееся гнездо, война фракций (`L07`) |
| Функция NPC | Роль-услуга NPC (торговля, мастерская, толкования…); преемственность — `L08` |
| Сопровождение | Ключевой NPC идёт за игроком в реальном времени через переходы до якоря (`L07` R21, `K03` R16) |
| Восходящий | Существо, которое поднимается по Башне: игрок, соперники, часть NPC |
| Соперник | Именной восходящий без кармана, который растёт параллельно игроку (`L09`) |
| Ненасыть | Соперник Среза: Искра, пробудившаяся в Бездне раньше игрока; автор сквозной цепочки надписей Среза (`L09`, `N01`) |
| Лучина | Искра, застрявшая ниже порога, подопечная Сухостоя (`B04` §9); Летописец Лагеря при небоевом пути (`K03` R22) |
| Фракция | Разумное сообщество яруса (`L10`) |
| Помнящие | Культ Катакомб Забытых, первая фракция Среза: верят, что поглощение крадёт у мёртвых память, и хранят её в кости (`L10`) |
