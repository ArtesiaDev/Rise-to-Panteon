# Глоссарий

> Один термин — одно значение. Новый термин сначала добавляется сюда, потом используется в других документах.

## Мир

| Термин | Значение |
|--------|----------|
| Башня | Иерархия измерений целиком |
| Ярус | Одно измерение: свой биом, экосистема, правила. Номер яруса — глубина в Башне |
| Этаж | Полоса плотности внутри яруса. Выше этаж — плотнее среда |
| Локация | Связная часть этажа из нескольких комнат. Единица загрузки и симуляции |
| Длина яруса | Число этажей в нём |
| Плотность среды | Постоянная характеристика локации, лежит в полосе своего этажа. От неё считаются распад и давление |
| Запас жизненной силы | Истощаемая величина локации: от него зависят популяции и восстановление. Плотность среды не меняет |
| Врата Резонанса | Переход в следующий ярус. **Главные** — одни на ярус, с изначальным Стражем. **Малые** — необязательные, тайные, со Стражами-преемниками |
| Порог | Плотность, нужная для резонанса с Вратами. Без неё Врата не открываются — единственный жёсткий барьер |
| Рубеж | Ярус с мегабоссом; завершает главу |
| Гнездо | Комната-дом популяции вида в локации, одно на вид: там вид размножается, раненые отдыхают. В Прототипе без разорения; со Среза — очищенное (место кокона с бонусом), разорённое, подчинённое |
| Якорь | Точка отдыха, возрождения и связи мира с Лагерем: стартовый, у Врат, обычный. В Прототипе — по одному на этаж, без Лагеря |
| Шаг мира | Пересчёт мира вдали от игрока; идёт подшагами. У каждой локации свои часы |
| Событие шага | Отдых у якоря (в Лагере — у Очага), переход между локациями, кокон, смерть: применяет накопленный шаг. Вход в Лагерь шага не применяет |
| Накопленный шаг | Время мира, накопленное и ещё не применённое; событие шага применяет его целиком и обнуляет |
| Минимальный шаг | Нижняя граница шага: у кокона — только при успехе и раз на номер эволюции; у смерти — всегда, недостающая часть — только размножение (со Среза — и восстановление запаса); мини-боссы от него не растут |
| Догон, подшаг | Догон — применение шага к локации от её часов до «сейчас» подшагами по 0,1 ед.; при входе локация сначала догоняется, потом разворачивается в существ |
| Единица времени мира | Мера часов мира: стоимость уровня, к которому копится опыт |
| Запись изменений | Видимые изменения локации с последнего визита игрока; по ней при входе расставляются следы |
| Предыстория (мира) | Детерминированный прогон 5–8 ед. времени мира при создании мира (и при достройке): на этажах 2–3 уже живут 1–2 выросших мини-босса. Не путать с предысторией NPC |
| Seed | Зерно генерации мира: планировка, расселение, содержимое находок. Тот же seed при той же версии генератора — тот же стартовый мир |
| Соль мира | Время создания мира; входит в зерно вариантов эволюции: планировка общая по seed, варианты линек — нет |
| Миграция | Уход части популяции в соседнюю локацию своего яруса — только шагом мира (прирост сверх ёмкости, голод). Со Среза |
| Страховка | Граница, за которую мир не заходит: вид не вымирает во всём ярусе, запас не падает до нуля, место Стража занимается, ключевые NPC и функции защищены, есть доступный якорь. Ограничивает мир, а не игрока |
| Последнее увиденное | Состояние места, каким персонаж видел его в последний раз: так его показывают карта и раздел журнала «Знакомые»; при смерти не теряется |
| Время мира | Часы мира: идут по прогрессу игрока (поглощённая сила в долях стоимости уровня); со Среза — ещё фиксированные доли: небоевое решение с наградой — 0,25 ед., проход изначального Стража любым путём — 1 ед. (J14) |
| Переход | Парный проход между локациями: на этаже — отрезок общей границы; вверх и вниз — объект у края локации. Врата — отдельно |
| Зона перехода | Проём перехода: игрок в нём недосягаем — существо уходит в гнездо; кокон здесь начать нельзя |
| Снимок мира | Полное сохранение мира: на каждом событии шага, по таймеру (~30 с), при сворачивании приложения и при снятии флага «в бою» |
| Ключ | Не предмет, а счётчик «ключи этой локации»: не теряется, не уходит в Эхо; один ключ — одна дверь своей локации |
| Запертая дверь | Непроходима для всех, пока не открыта: ключом, изнутри без ключа или взломом силой — с разрыва в стадию с локацией (под приглушением нельзя). Выбитая дверь — отдельное состояние |
| Сокровищница | Комната за запертой дверью с контейнерами, хотя бы в одном — предмет; на этаже 1 есть всегда |
| Ступень деградации | Со Среза: 0–3 — насколько локацию разрушило давление (трещины, сколы, поваленный декор). Не путать со ступенью истощения — её след выцветание |
| След | Видимое в мире последствие события |
| Слух | Сообщение о значимом событии, у которого есть след: реплика NPC, реакция персонажа, запись в журнале. В Прототипе — только реакция персонажа |

## Персонаж

| Термин | Значение |
|--------|----------|
| Плотность (персонажа) | Сила персонажа. Измеряется в уровнях |
| Действующая плотность | Плотность с учётом приглушения: меньшая из истинной и плотности среды |
| Разрыв | Разница плотностей в уровнях. «Разрыв в стадию» — не меньше ширины стадии более слабой стороны (локации или жертвы) |
| Порог стадии | Уровень, на котором стоит метаморфоза: дальше уровень не растёт до её завершения |
| Ширина стадии | Число уровней в стадии: Искра 10, Сгусток 15 (`E02`). Мера «разрыва в стадию» |
| Уровень | Ступень плотности. Даёт очки характеристик и базовый рост здоровья и урона |
| Характеристики | Мощь (Воин), Воля (Маг), Ловкость (Следопыт), Тлен (Некромант) — рабочие названия. Из них выводятся здоровье, урон и т. д. |
| Закреплённая добыча | Предметы, донесённые до якоря (отдых) или (Срез) через него в Лагерь. Незакреплённые при смерти уходят в Эхо. Валюты и материалы отдых не закрепляет — они в безопасности только в Хранилище |
| Опыт | Прогресс к следующему уровню |
| Стадия | Группа уровней; степень воплощения (Искра … Вознесённый) |
| Поглощение | Получение плотности и эссенции из существа |
| Эссенция | Качество поглощённого вида. Эссенции объединены в семейства |
| Семейство | Группа эссенций родственных видов (в Прототипе — Хитин, Разряд, Пыль, Гниль): общие базовое тело и сменные части, цвет облика, вес по полюсам |
| Состав | Накопленные эссенции персонажа |
| Тяготение к полюсам | 4 полосы близости облика к полюсам; считается только из состава, очки характеристик не влияют |
| Скудная добыча | Меньше опыта и эссенции от жертвы слабее: одна кривая от разрыва с жертвой — опыт почти до нуля, эссенция уменьшенная, но не нулевая |
| Черта | Единица облика. Типы: активная способность, модификатор атаки, усиление, сменная часть тела. У черты есть ранги |
| Лимит черт | Сколько черт несёт облик; растёт с каждой метаморфозой |
| Слот способности, набор | Ячейка для активной черты — одна кнопка: Искра 1, Сгусток 2, Тень 3, стадия 3+ — 4. Расстановка по слотам — набор. Пустой слот заполняется сразу, занятый меняют у якоря |
| «В запасе» | Активная черта без слота: не действует, пока не займёт слот |
| Базовая атака | Атака тела на отдельной кнопке: Искра — импульс (снаряд, «энергия»), Сгусток — удар (физический); на Тени тип задаёт оружие, со стадии 3 — тело |
| Источники вариантов | И1 — доминирующая эссенция, И2 — недавняя или редкая, И3 — рост ранга, И4 — сдвиг к полюсу |
| Отложенная линька | Линька, которую игрок не запустил: копится не больше одной; уровень стоит, опыт копится сверх и при смерти уходит в Эхо |
| Оболочка кокона | След кокона: пустая — после успеха, 20–30 с манит хищников (приманка); разорванная — после разрушения, только след |
| Ореол | Свечение облика: цвет — от доминирующего семейства; мерцает у входа в более плотную локацию, гаснет под действующим приглушением; для скрытности это «свет» |
| Статус, тип урона | Статус — горение, отравление, замедление, проклятие: обновляется без стопок, это не распад. Тип урона — 4–5 на главу, выводятся из семейств; «физический» — один из них |
| Номер поколения | Счётчик Искр мира в «Наследии»; входит в зерно вариантов |
| Поток силы | Визуал автопоглощения: сила летит от тела к игроку |
| Облик | Совокупность черт персонажа |
| Форма | Облик стадии 3+ как узнаваемый архетип (Берсерк, Пиромант…) |
| Полюс | Одна из четырёх осей пространства обликов: Воин, Маг, Следопыт, Некромант |
| Линька | Малая эволюция: новые черты |
| Метаморфоза | Большая эволюция: смена стадии |
| Кокон | Уязвимое состояние во время линьки или метаморфозы |
| Номер эволюции | Общий счётчик линек и метаморфоз — входит в зерно вариантов |
| Рост ранга | Источник вариантов эволюции: усиление уже имеющейся черты |
| Малое здоровье | Граница здоровья (ориентир 20–25%), на которой ломается кокон |
| В бою | На игрока охотятся или с последнего урона прошло меньше 4 с — один флаг для всех систем |
| Распад | Воздействие среды плотнее персонажа: сначала ослабление, при большем разрыве — потеря здоровья. Не урон и не статус |
| Давление | Воздействие персонажа на среду слабее его: с разрыва в стадию локации — страх, скудная добыча, трещины, взлом дверей |
| Волна страха | Всплеск страха при снятии приглушения, если оно держалось не меньше N секунд: пугает всё слабое рядом |
| Страх | Реакция существ и NPC на давление при разрыве с действующей плотностью не меньше ширины стадии существа: звери бегут и прячутся, разумные склоняются и говорят «со страхом»; под приглушением страха нет. Не путать с устрашением (шкалой фракции) |
| Приглушение | Переключатель (с первой метаморфозы, доступен везде): действующая плотность = меньшая из истинной и плотности среды. В коконе включается принудительно |
| Метка опасности | Цвет + форма у существа: 5 ступеней (намного слабее … намного сильнее) по разрыву между существом и действующей плотностью персонажа; та же шкала — у переходов и на карте. У NPC и своих призванных её нет |
| Индикатор готовности | Элемент HUD: «линька готова» или «метаморфоза готова» |
| Реакция персонажа | Одна строка-мысль персонажа над ним, без паузы: что произошло, а не куда идти; только увиденное. Первое знакомство — с базовым правилом, раз на мир, в бою — сразу; ситуативные — с кулдауном, в бою ждут. «Реплика» — её текст |
| Медленный шаг | Скрытное движение (Срез): малое отклонение стика, без атак; на клавиатуре — удержание модификатора |

## Существа и NPC

| Термин | Значение |
|--------|----------|
| Вид | Тип существ с общей эссенцией, поведением и внешностью |
| Популяция | Численность вида в локации — так мир хранит существ вдали от игрока |
| Трофический уровень | Место вида в пищевой сети: Т0 пасутся у точек кормёжки, Т1 — падальщики, Т2 — хищники, Т3 — вершинные хищники. Смещает уровень особи: −1 / 0 / +1 / +2 (не ниже 1) |
| Точка кормёжки | Место пастьбы нижнего уровня пищевой сети |
| Приём | Уникальное действие вида (1–2 у вида, +1 у мини-босса); становится кандидатом черты, если такая черта есть в каталоге |
| Рядовое существо | Не мини-босс, не Страж, не соперник; если не плотнее игрока, поглощается само |
| Поимённое существо | Существо, которое мир хранит отдельно, а не числом популяции: мини-босс, Страж, носитель Эха, соперник, NPC |
| Приманка | То, чем игрок отвлекает существ: тело, пустая оболочка кокона, Эхо |
| Ослабленное существо | Существо со здоровьем < 25%: уходит в гнездо восстанавливаться. Не путать с фазой ослабления распада |
| Логово | Гнездо, в котором живёт мини-босс |
| Мини-босс | Особь вида, выросшая от поглощения. Ведётся поимённо |
| Ступень роста | «Эволюция» существа внутри вида: размер, эффекты, части. Мини-босс в Прототипе — одна ступень, в Срезе — 2–3 |
| Страж Порога | Роль у Врат. **Изначальный** — уникальный, ручной работы. **Преемник** — занявший место убитого: возвышенное или зарождённое существо с шаблоном Стража либо соперник |
| Место Стража | Роль у главных Врат, которая не пустует: убитого сменяет преемник; пока место пусто, Врата держат, будто Страж на месте (J22) |
| Возвышение, зарождение | Как мир назначает преемника: возвышение — мини-босс этажа Врат получает шаблон Стража; зарождение — если мини-босса нет, Врата создают Стража из особи сильнейшего вида этажа. Не путать со стадией «Вознесённый» |
| Шаблон Стража | Общие данные роли поверх любого вида: фазы, механики арены, поза поклона, титул |
| Проход через Стража | Второй ключ Врат (первый — резонанс): бой или небоевой путь; прошедшего однажды Страж и преемники больше не держат |
| NPC | Разумное существо, с которым можно говорить; может переехать в Лагерь. Предыстории разные: восходящие (застрявшие или идущие своим путём), местные, изгнанники и беглецы |
| Ключевой NPC | Авторский NPC с авторской просьбой; защищён до встречи с игроком; в Лагерь — только с сопровождением |
| Встреча | Момент, снимающий защиту «до встречи»: для NPC — первый разговор, для изначального Стража и авторской вставки — первое появление в поле зрения |
| Мегабосс | Изначальный Страж Рубежа: плотность — верх полосы яруса 10; его проход любым путём — финал главы |
| Восходящий | Существо, которое поднимается по Башне: игрок, соперники, часть NPC |
| Соперник | Именной восходящий, который растёт параллельно игроку |
| Фракция | Разумное сообщество яруса. Пока член фракции состоит в ней, в Лагерь он не переезжает |
| Носитель Эха | Существо, поглотившее Эхо игрока |

## Лагерь, смерть, экономика

| Термин | Значение |
|--------|----------|
| Лагерь | Личный резонансный карман игрока |
| Хранилище | Место в Лагере, где вещи в безопасности |
| Эхо Души | Остаток силы игрока на месте гибели |
| Отдых | Действие у якоря: ~2 с, не «в бою», прерывается уроном. Полное лечение, замена способностей в занятых слотах, закрепление предметов, шаг мира; задаёт точку возрождения |
| Наследие | Хардкор-режим: смерть навсегда, мир остаётся |
| Предмет | Обычное снаряжение |
| Реликвия | Высшая ступень редкости: уникальный эффект, одна на мир, аура. У изначального Стража — только за бой, у фракций — за амбру; продать нельзя |
| Живица | Расходник: поглощаемая капля жизненной силы. Доступна с Искры |
| Внутренние слоты | Слоты для сердцевин и осколков силы, которые тело вбирает. Есть с Искры |
| Сердцевина, осколок силы | Предметы внутренних слотов |
| Внешние слоты | Слоты для снаряжения, которое тело держит и носит. Появляются со Сгустка |
| Грубый предмет | Предмет единственного внешнего слота Сгустка: заточенная кость, нарост |
| Покров, Знак | Внешние слоты Тени: накидка или обмотки; амулет или печать |
| Слот полюса | Внешний слот со стадии 3: второй хват или щит (Воин), фокус (Маг), колчан (Следопыт), сосуд (Некромант) |
| Быстрая ячейка | Кнопка для живицы |
| Контекстная кнопка | Одна кнопка на все действия с фиксированным приоритетом: поглотить; подобрать; открыть или выбить, разорить гнездо; говорить, подчинить; пробудить якорь, отдохнуть, войти в Лагерь; кокон — последним. В Лагере — ещё «выйти»; в коконе — только «выйти» (равно разрушению) |
| Атлас | Раздел экрана Персонажа, доступный везде: поглощённые виды, их семейство, увиденные черты. В Лагере Летописец добавляет толкования |
| Точка возрождения | Якорь последнего отдыха (не отдыхал — стартовый; заблокирован — предыдущий незаблокированный). Со Среза персонаж возрождается в Лагере, и этот якорь — точка выхода из него |
| Золото | Общая валюта |
| Амбра | Редкая валюта; источники только конечные |
| Кошель | Порция амбры изначального Стража — одна на все пути прохода |
| При себе | Валюты и материалы вне Хранилища: при смерти уходят в Эхо, отдых их не закрепляет, при входе в Лагерь сдаются автоматически |
| Материалы | Кость, хитин и т. п. — для улучшения предметов и Лагеря, оплаты товаров фракций. Не валюта |
| Уровень предмета | Плотность предмета в уровнях — плотность источника или поднятая в Мастерской. Действует на меньшей из своей и действующей плотности владельца; выше владельца — «на вырост» |
| Разбор | Уничтожение предмета (в том числе реликвии) ради материалов — только в Мастерской; живица не разбирается |
| Профиль устройства | Данные вне миров: настройки, флаги подсказок и окон (со Среза), Летопись прошлых Искр |
| Глава | Часть игры; завершается Рубежом |
| Подсказка управления | Жест или подсветка кнопки при первом использовании — только ввод и интерфейс, не мир |
| Системное окно | Неблокирующая плашка в 1–2 строки при первом появлении системы; идёт после реакции персонажа, «в бою» откладывается |
| Прототип | Первый этап разработки: проверка основной петли игры ([Scope.md](Scope.md)) |
| Срез | Вертикальный срез — второй этап: Бездна и Катакомбы, все столпы вместе ([Scope.md](Scope.md)). Третий этап — глава 1 (Гл1) |

## Срез и глава 1

| Термин | Значение |
|--------|----------|
| Состояния Врат | **Молчат** (нет резонанса) · **гудят** (резонанс есть, Страж не пройден) · **открыты** |
| Нижняя сторона Врат | Место, куда Врата выводят в следующем ярусе; от неё считается плотность этажа 1 этого яруса |
| Ручная вставка | Заранее сделанная комната или группа комнат, которую генератор ставит в процедурный мир |
| Тайник | Скрытое вместилище с добычей за стеной; открывается разрушением его приметы — ударом или давлением |
| Тайный ход | Скрытый проход внутри локации (обход, срезка) или между локациями (дополнительное ребро графа); не входит в обязательные маршруты |
| Комплекс Врат | Ручная вставка на верхнем этаже, одна на ярус: арена изначального Стража, преддверие с якорем у Врат, зал Врат |
| Примета | Видимый признак тайника или тайного хода (трещина и т. п.) |
| Эффект среды | Огонь, яд, вода и т. п. на клетках тайловой сетки; одинаков для всех |
| Цитадель | Ручная часть Рубежа, где живёт мегабосс |
| Предел главы | Порог последней стадии главы: выше уровень в этой главе не растёт. Глава 1 — порог стадии 4; Врата Рубежа выше предела и молчат (J1) |
| Финал главы | Один раз на мир, при проходе мегабосса любым путём; 3–4 исхода с окраской по полюсу; после финала можно остаться в мире |
| Достройка | Однократное добавление ярусов новой главы в существующий мир при первой загрузке новой сборкой: из того же seed, с предысторией; созданное не меняется |
| Цикл перестройки | Период, за который локации Теневого Разлома переключаются между заранее построенными вариантами |
| Единица силы | Сила одной рядовой особи среднего размера; мера запаса жизненной силы и её оборота («поток силы» — только визуал поглощения) |
| Ступень истощения | Насколько выжата локация (0–3); задаёт следы и численность |
| Ёмкость | Предел популяции вида в локации — 1,5× стартовой; прирост сверх уходит мигрантами |
| Доля шага | Фиксированная прибавка к накопленному шагу: небоевое решение с наградой — 0,25 ед., проход изначального Стража любым путём — 1 ед.; одно решение — одна доля |
| Небоевое решение с наградой | Исход из закрытого перечня: подчинение, переезд в Лагерь, небоевой проход преемника Стража, награда за просьбу, союз с соперником. Торговля и повторная дань не считаются; проход изначального Стража — отдельная доля 1 ед. (J25) |
| Небоевой путь | Проход изначального Стража без боя: длящаяся награда и полное откровение; реликвии нет |
| Журнал событий симуляции | Единый внутренний журнал значимых событий мира: источник слухов и толкований Хроники; следы строятся по записи изменений. Не путать с журналом игрока |
| Класс события | Значимость события для слухов: А — крупное, Б — заметное, В — фон. Слухи и журнал — только А и Б |
| Видимая угроза | Угроза NPC со следом и слухом (разрастающееся гнездо, война фракций): NPC гибнет только от неё |
| Журнал | Экран игрока, память персонажа: разделы Просьбы · Увиденное · Слухи · Лор · Знакомые. Только то, что персонаж видел или слышал |
| Хроника | Толкования Летописца к записям журнала («кто и почему»); в Гл1 — итоговая запись главы. Новых событий не открывает |
| Летописец | NPC Лагеря: Хроника, толкования Атласа, эволюционные услуги. В Срезе — Лучина (небоевой путь у Стража Бездны) или преемник функции (J17) |
| Летопись прошлых Искр | История миров в профиле устройства: запись заводится при создании мира и дополняется на вехах; на игру не влияет |
| Функция NPC | Роль-услуга NPC (торговля, мастерская, толкования…). Ключевая при гибели носителя переходит преемнику; если носителя убил игрок — с задержкой и потерями |
| Торговец | Функция NPC и активность Лагеря: купля-продажа, живица всегда; скупает не дороже 25–30% цены; материалы не продаёт. В Срезе — концепт «Меняла» |
| Мастерская | Активность Лагеря (Мастер): разбор и подъём уровня вещей и реликвий; создание новых — пересмотр в Гл1 |
| Зал трофеев | Зона Лагеря: трофей — за бой со Стражем или соперником, дар — за небоевой путь; бонусов не даёт |
| Якорный камень | Объект выхода в Лагере: «выйти» открывает схему «ярусы → этажи → пробуждённые якоря» |
| Житель | NPC Лагеря без авторской функции, в том числе подчинённый разумный: активности нет |
| Сопровождение | Ключевой NPC в реальном времени идёт за игроком через переходы (не дальше 2) до пробуждённого якоря; не сражается |
| Подчинение | Постоянная покорность из страха: гнездо зверей (действие «подчинить»), разумный или фракция целиком (разговор со страхом). Не нападают, уступают путь, платят дань; снимается нападением игрока или разорением |
| Дань | Ресурсы, которые подчинённые копят у гнезда по времени мира и оставляют игроку; амброй не бывает |
| Очищенное гнездо | Гнездо без хозяев в комнате при живом виде в локации — место кокона с бонусом |
| Разорённое гнездо | Гнездо, разрушенное действием «разорить»; вид больше не размножается в этой комнате |
| Репутация, устрашение | Две шкалы отношения фракции к игроку: доверие и покорность силе |
| Контроль (фракции) | Доля локации под властью фракции. Не путать с эффектами контроля в бою (отбрасывание, оглушение) |
| Святыня | Место фракции на якоре; освобождается договором или силой |
| Знамёна | След территории фракции в локациях под её контролем |
| Веха | Шаг пути соперника вдали от игрока: ярус, этаж, событие. В Летописи прошлых Искр — строка пути игрока |
| Занятый, заблокированный якорь | Занятый — обычный якорь с гнездом, логовом или святыней до пробуждения. Заблокированный — пробуждённый, перекрытый миром вдали. Неблокируемые — стартовый, у Врат, цитадели Рубежа |
| Место NPC | Заранее подготовленное место в Лагере под NPC и его активность. Не путать с местом NPC в мире (стоянкой) |
| Очаг | Центр Лагеря: отдых как у якоря — лечение, замена способностей, шаг мира; не сохранение |
| Предшественник | Погибшая Искра в «Наследии»; остаётся частью мира |
| Старые записи, старая карта | Журнал и карта предшественника у новой Искры в «Наследии» — заведомо устаревшие |
| Большой шаг мира | «Прошли годы» между жизнями в «Наследии» |
| Отмеченный предмет | Предмет с 1–2 свойствами сверх шаблона (редкость между простым и реликвией) |
| Перерастание | Замена черты X на Y — только на первой линьке после смены доминирующего вида в составе; ранг X переходит к Y, если они одного типа |
| Эволюционная услуга | Платная услуга Летописца: переброс вариантов, перераспределение очков |
| Призванный | Существо, поднятое игроком из останков (полюс Некромант) |
| Фрагмент лора | Надпись на стене, описание предмета или находка — записка (не предмет, сразу в журнал) или артефакт (предмет) |
| Откровение | Лор измерения от изначального Стража: кусочек — в сцене встречи, при любом пути; полный рассказ — награда небоевого пути. На Рубеже — крупное откровение главы |
| Катсцена | Короткая движковая сцена (5–30 с) с текущим обликом: раз на мир, не «в бою», локация на паузе; пропуск удержанием, сказанное — в журнал |
| Просьба | Задание NPC без маркеров: текст + запись в журнале |
| Режим разговора | «Со страхом» (разрыв действующей плотности с собеседником — в ширину его стадии) или «на равных»; под приглушением — на равных |
| Сигнал читаемости | Звук или визуальный признак, который объясняет событие без текста |
