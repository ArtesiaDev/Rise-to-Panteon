## Проверить в прототипе

План испытаний Прототипа: эти вопросы решаются замером, а не обсуждением. Детали и критерии — в файлах фич.

| Фича | Что проверяем |
|------|---------------|
| E01 | Величина лечения от поглощения |
| E03 | Читаются ли очки характеристик как выбор |
| E04 | Не сходятся ли составы эссенций у разных игроков |
| E05 | Нужна ли видовая разница черт внутри семейства уже в Прототипе |
| E06 | Баланс источников вариантов линьки |
| E07 | Не теряется ли удовольствие от боя после перехода Искры в ближний бой |
| E08 | Как часто разрушается кокон метаморфозы |
| B02 | Хватает ли видимых охот для читаемости экосистемы |
| L01 | Не «замерзает» ли мир, когда игрок возвращается в слабые места |
| L03 | Устойчива ли пищевая сеть |
| K02 | Хватает ли одного стартового якоря на 2–3 этажа |
| I01 | Не превращается ли цикл смертей в фарм мини-боссов |
| W02 | Хватает ли процедурных комнат для интересного боя |
| W13 | Не становится ли периодическая ловушка фермой |
| U01 | Сколько ошибок даёт контекстная кнопка |
| U03 | Сколько ступеней метки опасности различает игрок |
| U07 | Не перегружен ли выход из метаморфозы окнами и репликами |

## На следующие итерации

- Стадии и главы: сколько глав до Пантеона; как стадии 5–6 распределяются по главам.
- Призыв (полюс Некромант): источник, лимит, поведение `C09`.
- Скрытность: модель обнаружения, влияние света `C08`.
- Предметы: свойства и редкость; крафт — создание или только улучшение.
- Урон: список типов и статусов; эффекты среды и их взаимодействия `W17`.
- Механизм передачи функций погибшего NPC `L08`.
- Детализация фич вертикального среза по шаблону (итерация 3).
- Небоевой прогресс и часы мира: двигают ли небоевые решения шаг мира `L01`.
- Структура Рубежа и мегабосс `W18`, `B06`.
- Нестабильные измерения (Теневой Разлом) — перегенерируются со временем? `W19`.
- Какие ярусы получают фракции (кандидаты — в [LivingWorld.md](LivingWorld.md)).
- Реестры: «преграда × решение» (гарантия столпа 4), «событие → след → слух», сохраняемые данные,
  таблица прогрессии «ярус → этажи → уровни → стадия → порог».
- Параметры в прототипе: размеры этажей и локаций, длительность кокона, число шагов неприкосновенности Эха
  и появления преемника, лимиты существ.
