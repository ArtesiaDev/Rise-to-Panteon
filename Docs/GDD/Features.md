# Реестр фич

> Карта всех фич игры. ID стабильны и не перенумеровываются.
> Правила фич живут в тематических документах. По мере детализации фича выносится в отдельный файл
> `Features/<ID>-<Name>.md` по [шаблону](_FeatureTemplate.md) — сначала фичи Ядра.

**Статусы:** ✅ решено (детали — параметры баланса) · 🟡 основа есть, детали открыты · ❓ ждёт ответа автора ·
⏳ позже.
**Этапы** ([Scope.md](Scope.md)): Ядро — прототип ядра · Срез — вертикальный срез · Гл1 — глава 1.
