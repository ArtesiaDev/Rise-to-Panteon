# Экономика

Термины — [Glossary.md](Glossary.md). ID фич — [Features.md](Features.md).

## Принципы

- **Универсальные валюты нужны** — иначе нормально не играется. Их несколько, для разных вещей.
- **NPC и фракции** назначают цены в разных валютах и материалах: культу нужна кость, улью — материал «кристалл».
- Поглощение — не валюта: оно остаётся чистым прогрессом ([Evolution.md](Evolution.md)).

Отклонено: сгустки силы как валюта (в духе Dark Souls).

## Валюты `I08`

| Валюта | Для чего | Источники |
|--------|----------|-----------|
| Золото | Торговля, услуги NPC, обычные предметы, расходники | Продажа, лут, оплата фракций |
| Амбра | Реликвии, эволюционные услуги, улучшение Лагеря | **Только конечные:** изначальные Стражи, тайники, соперники, небоевые решения |

## Материалы `I09`

- Кость, хитин, материал «кристалл» и т. п. — с существ и биомов. Не валюта.
- Идут на крафт и улучшение предметов, улучшение Лагеря, обмен с фракциями.
- Список по ярусам — позже.

## Стоки и защита от арбитража `I10`

| Правило | Зачем |
|---------|-------|
| Расходники — постоянный сток золота | Золото не копится без смысла на поздних стадиях |
| Цена «получить варианты линьки заново» растёт с каждым использованием на одной линьке | Переброс не обесценивает выбор |
| Фракции принимают материалы только в оплату своих товаров и обратно их не продают | Нет перепродажи между фракциями |
| Торговец покупает не дороже 25–30% цены продажи | Нет арбитража с торговцем |
| Предметы можно разобрать на материалы | Сток лишних предметов |
