# Мир — Башня измерений

## Структура

```
Башня (иерархия измерений)
 └─ Ярус = измерение: свой биом, экосистема, правила
     └─ Этаж = полоса плотности внутри яруса (выше этаж — плотнее среда)
         └─ Локации = процедурные подземелья, связанные в граф
```

- **Ярус** — отдельная реальность. Переход между ярусами — через **Врата Резонанса**, это смена реальности,
  а не просто следующий этаж.
- **Этажи** внутри яруса упорядочены по плотности жизненной энергии: чем выше этаж, тем плотнее среда
  и сильнее обитатели.
- Каждый этаж состоит из нескольких **локаций**, связанных между собой.

---

## Открытость

Мир — нелинейный граф, а не коридор:

- несколько маршрутов между этажами, тайные ходы;
- у яруса может быть несколько Врат Резонанса;
- движение в любую сторону: вверх, вниз, назад в пройденные ярусы.

Игрока ничто не запирает. Ограничивает только **плотность**.

## Плотность и мягкие барьеры

Всё решает плотность накопленной жизненной энергии ([Evolution.md](Evolution.md)).
У каждой локации своя плотность среды. Несоответствие плотности персонажа и локации даёт эффект в обе стороны.
Сила эффекта растёт с разрывом.

### Локация плотнее персонажа — распад

Персонаж **распадается** — «как пламя свечи в шторм».

| Разрыв | Эффект |
|--------|--------|
| Небольшой | Ослабление |
| Средний | Постепенная потеря здоровья |
| Большой | Стремительный распад |

Вылазки выше своего уровня возможны и окупаются: существа там сильнее, но за победу над ними —
больше опыта и плотности, быстрее эволюция. Чем ближе плотность персонажа к плотности этажа,
тем слабее распад ([Evolution.md](Evolution.md) → риск и награда).

### Локация слабее персонажа — давление

- **Скудная добыча.** Поглощение слабых почти ничего не даёт — они слишком «разрежены».
  Бесконечно фармить внизу нельзя.
- **Страх.** Слабые существа чуют тебя: бегут, прячутся или склоняются.
  С некоторыми можно говорить, некоторых — подчинить.
- **Давление на реальность.** Твоя плотность давит на слабый мир: трескаются полы, гибнут слабейшие
  существа рядом, локация деградирует — и это сохраняется (столп «Мир помнит»).

### Приглушение плотности

Отдельная способность: позволяет возвращаться в слабые места, не разрушая их.
Без неё вернуться вниз, не ломая мир, логически невозможно.

- **Переключатель.** Пока включено, сила персонажа опускается до уровня локации: он слабее,
  но мир не трещит, существа не разбегаются, с ними можно говорить.
- Выключил в опасности — давление на реальность сразу возвращается.
- Открывается при первой метаморфозе (Искра → Сгусток).

Не делаем: утечку силы при спуске (наказание за возвращение противоречит свободе).

## Постоянство мира

- Мир генерируется **один раз на сохранение** из seed этого сохранения.
- Изменения сохраняются (столп «Мир помнит»): смерть игрока не сбрасывает и не перегенерирует локации.
- Реиграбельность — через новое сохранение: новый seed, новый мир.

## Генерация

**Гибридный подход:**
- **Фиксировано** (ручная работа): логово Стража Порога, Врата Резонанса, нарративные точки, секретные сюжетные комнаты.
- **Процедурно:** планировка локаций, связи графа, расстановка существ, лут, ловушки.

Визуал — заранее подготовленные ассеты (тайлы, спрайты, декор), которые расставляет генератор.

### Ориентир карты

Референсы: [References/MapGeneration/](../References/MapGeneration/)

- тайловая сетка, вид сверху в 3/4; у стен лицевая сторона высотой в клетку с декором (факелы, знамёна, окна);
- плотно упакованные комнаты почти без пустоты между ними; проёмы и короткие проходы шириной 1–2 клетки;
- замки и ключи, сокровищницы, разрушаемые объекты (бочки), ловушки (шипы), логово босса;
- миникарта с иконками объектов.

Референсы задают стиль комнат, а не масштаб этажа. Размер комнат — [Combat.md](Combat.md) → масштаб.

## Размер этажей

**Этажей меньше, но каждый — внушительного размера.**

- Механики живого мира (экосистема, фракции, соперники, миграции) работают, только если им есть где
  развернуться. Маленький этаж, как карта из референса, их не вместит.
- Меньше этажей на ярус — меньше однообразия одного биома.
- Точные размеры и количество — в прототипе ([Scope.md](Scope.md)).

## Ярусы

> Длина ярусов относительная — в пропорциях лорных причин.
> Числа этажей из старого концепта (10–35 на ярус) не действуют.

| Ярус | Измерение | Лорная причина длины |
|------|-----------|----------------------|
| 0 | Бездна | Иссохшее, почти мёртвое измерение |
| 1 | Катакомбы Забытых | Тесное кладбищенское пространство |
| 2 | Кристальные Недра | Разветвлённые минеральные тоннели |
| 3 | Живые Туннели | Органические ходы сжимаются — нет времени задерживаться |
| 4 | Затопленные Залы | Огромные подводные руины |
| 5 | Пепельные Кузни | Промышленный лабиринт шахт |
| 6 | Костяные Поля | Бескрайние залы из останков гигантов |
| 7 | Теневой Разлом | Нестабильное измерение — схлопывается, нет времени |
| 8 | Адские Горнила | Раскалённый бесконечный ад |
| 9 | Кристальная Пустота | Пространство без форм, чистая концентрированная энергия |
| 10 | **Первый Рубеж** | Первый великий Рубеж — финал главы 1 |
| 11 | Туманные Равнины | Плоское туманное пространство, дезориентация |
| 12 | Гнилые Болота | Медленное, вязкое, заразное измерение |
| … | … | Продолжают расти с отклонениями по лору |

## Ключевые существа

### Страж Порога
Каждый изначальный Страж уникален: имя, короткий разговор при встрече, собственная механика боя.
Лорно: существа, занявшие место у Врат Резонанса, чтобы не пропустить слабых.
Кроме боя у каждого Стража есть хотя бы один небоевой путь — свой для каждого.
Что происходит после смерти Стража — [LivingWorld.md](LivingWorld.md).

### Мини-боссы
Обычное существо яруса, которое поглотило достаточно других, чтобы разрастись до размеров комнаты.
Механически интереснее рядового врага, но без нарратива. Появляются из симуляции экосистемы,
а не по скрипту (столп «Один закон для всех»).

### Рубежи
Каждые ~10 ярусов — **Рубеж**: ярус с мегабоссом и крупным нарративным откровением.
Рубеж завершает главу ([Scope.md](Scope.md)). Внутренняя структура Рубежа — отдельный этап дизайна.
