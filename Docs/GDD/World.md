# Мир — Башня измерений

Термины — [Glossary.md](Glossary.md). ID фич — [Features.md](Features.md). Правила, числа и граничные случаи —
в файлах фич.

## Зачем игроку система мира

- **Свобода вместо коридора.** Мир — нелинейный граф локаций: идти можно вверх, вниз и назад, игрока ничто
  не запирает. Ограничивает только плотность — мягкими барьерами; единственный жёсткий барьер — резонанс у Врат.
- **Один закон для всех.** Плотность, распад, давление, ловушки и эффекты среды действуют на игрока и существ
  одинаково.
- **Мир помнит.** Мир создаётся один раз из seed; сделанное игроком остаётся, смерть мир не сбрасывает.
- **Неизвестность.** Планировка каждого мира новая; авторские и скрытые места находят без маркеров.
- **Тело не запирает.** Тропу тела открывает рывок своего семейства, ключ к миру оси Круга или ремесло; мест только
  для одного тела нет (`W15`).

## Структура мира: ярус → этаж → локация

```text
Башня (иерархия измерений)
 └─ Ярус = измерение: свой биом, экосистема, правила
     └─ Этаж = полоса плотности внутри яруса (выше этаж — плотнее среда); одна карта без загрузок
         └─ Локации = участки экосистемы из угодий, соединённые перевалами в граф
```

## Как фичи мира работают вместе

1. **Создание.** Мир создаётся один раз: иерархия, типы локаций и граф — по эталонным планировкам этажей, одним
   во всех мирах; seed задаёт наполнение — популяции, содержимое находок (`W01`, `W02`, `W03`, `W10`). Генератор
   (`W02`) строит локации по эталону: угодья по типу локации и грамматике этажа, ручные вставки (`W04`) и точки
   интереса — печати и ключи (`W12`), ловушки (`W13`), контейнеры (`W14`), скрытые места и тропы тела (`W15`),
   клетки эффектов среды (`W17`), точки всплеска силы (`W20`); генератор вариаций — Гл1, до производства ярусов 2–10.
   Биом (`W11`) задаёт облик яруса, его виды и грамматику этажей; облик и форму места, как и облик существ, задаёт
   телесность его плотности ([Lore.md](Lore.md) → плотность и телесность).
2. **Плотность.** Плотность среды локации постоянна и видна до входа (`W05`); всё решает разрыв с плотностью
   персонажа. Локация плотнее — распад (`W06`); слабее на целую стадию — давление (`W07`); приглушение (`W08`)
   опускает действующую силу до плотности места, чтобы пройти его, не разрушая.
3. **Движение.** Этаж — одна карта: его локации связаны перевалами без загрузки, этажи — переходами (`W16`),
   всё вместе — граф (`W03`): вниз — всегда свободно, вверх внутри яруса не пускает только распад. Ярусы соединяют
   Врата Резонанса (`W09`) — резонанс и проход Стража. Существа границ локаций в реальном времени не пересекают,
   кроме свиты игрока (`W16`, `C11`). Каждые ~10 ярусов — Рубеж с мегабоссом и финалом главы (`W18`).
4. **Память.** Изменения сохраняются, локации вдали живут по своим часам (`W10`): трещины давления, выбитые печати,
   вскрытые контейнеры и скрытые места остаются. Исключение — перестройка нестабильных измерений (`W19`).
