# Мир — Башня измерений

Термины — [Glossary.md](Glossary.md). ID фич — [Features.md](Features.md). Правила, числа и граничные случаи —
в файлах фич.

## Зачем игроку система мира

- **Свобода вместо коридора.** Мир — нелинейный граф локаций: идти можно вверх, вниз и назад, игрока ничто
  не запирает. Ограничивает только плотность — мягкими барьерами; единственный жёсткий барьер — резонанс у Врат.
- **Один закон для всех.** Плотность, распад, давление, ловушки и эффекты среды действуют на игрока и существ
  одинаково.
- **Мир помнит.** Мир создаётся один раз из seed; сделанное игроком остаётся, смерть мир не сбрасывает.
- **Неизвестность.** Планировка каждого мира новая; авторские места, тайники и тайные ходы находят без маркеров.

## Структура мира: ярус → этаж → локация

```text
Башня (иерархия измерений)
 └─ Ярус = измерение: свой биом, экосистема, правила
     └─ Этаж = полоса плотности внутри яруса (выше этаж — плотнее среда)
         └─ Локации = связные группы комнат, соединённые в граф
```

## Как фичи мира работают вместе

1. **Создание.** Из seed один раз создаются иерархия, граф и популяции (`W01`, `W03`, `W10`). Генератор (`W02`)
   строит планировку локаций, встраивает ручные вставки (`W04`) и расставляет объекты: запертые двери и ключи
   (`W12`), ловушки (`W13`), контейнеры (`W14`), приметы тайников и тайных ходов (`W15`), клетки эффектов среды
   (`W17`). Облик, виды и параметры генерации яруса задаёт биом (`W11`).
2. **Плотность.** Плотность среды локации постоянна и видна до входа (`W05`); всё решает разрыв с плотностью
   персонажа. Локация плотнее — распад (`W06`); слабее на целую стадию — давление (`W07`); приглушение (`W08`)
   опускает действующую силу до плотности места, чтобы пройти его, не разрушая.
3. **Движение.** Переходы (`W16`) связывают локации в граф (`W03`): вниз — всегда свободно, вверх внутри яруса
   не пускает только распад. Ярусы соединяют Врата Резонанса (`W09`) — резонанс и проход Стража. Каждые ~10 ярусов —
   Рубеж с мегабоссом и финалом главы (`W18`).
4. **Память.** Изменения сохраняются, локации вдали живут по своим часам (`W10`): трещины давления, выбитые двери,
   вскрытые контейнеры и тайники остаются. Исключение — перестройка нестабильных измерений (`W19`).
