# F-W03 Граф маршрутов, свободный спуск

> **Система:** Мир · **Статус:** детализировано (итерация 2) · **Этап:** Прототип · **Столпы:** Неизвестность, Мир помнит · ощущения: свобода, первооткрыватель
> Основа — [World.md](../World.md) → открытость. Термины — [Glossary.md](../Glossary.md), сквозные решения — [DecisionLog.md](../DecisionLog.md).
>
> **В Прототип входит:** граф локаций Бездны, несколько маршрутов между этажами, движение в любую сторону.
> **Позже:** спуск через Врата и возвращение в пройденные ярусы (`W09`, Срез), тайные ходы (`W15`, Срез),
> миграция по рёбрам (`L03`, Срез).

## 1. Суть
Мир — сеть локаций, а не коридор: на следующий этаж ведут несколько путей, идти можно в любую сторону — вверх,
вниз, назад. Вниз всегда свободно. Не пускает только плотность.

## 2. Зачем
- «Свобода» и «первооткрыватель»: выбор маршрута, петли, возвращения.
- Мягкие барьеры имеют смысл, только когда есть куда идти вместо стены.
- Возвращение вниз — основа давления и приглушения (`W07`, `W08`) и наград за возвращение (`W12`, `W15`).
- Без фичи — линейная стопка этажей (отклонено).

## 3. Лор
[Lore.md](../Lore.md) → почему нельзя просто прыгнуть выше: разрушается существо **ниже** порога — подъём.
В разреженное измерение спускаться безопасно, поэтому вниз резонанс не нужен.

## 4. Правила
- **R1.** Узлы графа — локации, рёбра — переходы (`W16`). Между ярусами — рёбра через Врата (`W09`).
- **R2.** Граф нелинейный: между соседними этажами несколько маршрутов — не меньше двух переходов вверх
  в разных локациях *(выведено: «несколько маршрутов между этажами»)*.
- **R3.** Все переходы двусторонние *(выведено: «движение в любую сторону»)*.
- **R4.** Спуск через Врата свободен — резонанс нужен только вверх (`W09`, Срез).
- **R5.** Игрока ничто не запирает: ни одно ребро не закрывается навсегда; ограничивает только плотность
  (распад `W06`). Единственный жёсткий барьер — порог Врат (`W09`).
- **R6.** Граф ярусов, этажей, локаций и переходов создаётся один раз при создании мира из seed и не меняется
  (`W10`). Ярусы будущих глав достраиваются из того же seed ([Meta.md](../Meta.md)).
- **R7.** Вернуться можно в любую посещённую локацию; в Срезе — и в пройденные ярусы.
- **R8.** Тайные ходы — дополнительные рёбра (`W15`, Срез).
- **R9.** Доступ к рёбрам не зависит от облика (`C04`).
- **R10.** Стартовая локация — на нижнем этаже Бездны (`W01` R15).
- **R11.** В доступной части яруса всегда хватает добычи, чтобы дорасти до плотности следующего этажа (`L12`).
  В Прототипе это держат: стартовые популяции с запасом, упрощённое размножение из запаса жизненной силы
  и страховка «последние особи вида в ярусе не съедаются» (G5); граф и расстановка проверяются бюджетом добычи.
- **R12.** Граф игроку не показывается: он узнаёт его исследованием — туман войны, карта последнего увиденного (`U05`).
- **R13.** Этаж — единая плоскость, поделённая на участки-локации; переходы между локациями этажа — на их общих
  границах; карта этажа — одна картинка *(решено, итерация 2)*.
- **R14.** Рёбер через этаж (шахт, провалов) в Прототипе нет: рёбра только между соседними этажами
  *(решено, итерация 2)*.
- **R15.** Переходы вверх стоят в локациях у верхней границы полосы этажа, переходы вниз — у нижней: плотность
  растёт по пути к переходу вверх (`W05` R14) *(решено, итерация 2)*.

## 5. Параметры
| Параметр | Значение | Статус |
|----------|----------|--------|
| Переходов вверх между соседними этажами | ≥ 2, обычно 2–3, в разных локациях | финал (≥ 2), ориентир |
| Переходов у локации | 2–4 | ориентир |
| Циклов на этаже | ≥ 1 | ориентир |
| Путь от стартовой локации до ближайшего перехода вверх | ≥ 2 перехода | ориентир |
| Тупиковых локаций на этаж | ≤ 1 | ориентир |
| Бюджет добычи | стартовый доступный опыт на этажах ≤ k ≥ 2× нужного, чтобы дорасти до полосы этажа k+1 | ориентир (G5, `L03`) |

## 6. Живой мир и читаемость
- **Вдали:** граф статичен. В Прототипе по рёбрам ничего не перемещается: минимальная симуляция вдали идёт внутри
  локаций (G5). В Срезе по рёбрам в шаге мира идут миграция видов (`L03`), подъём разросшегося мини-босса на этаж
  выше (G28), переход носителя Эха в соседнюю локацию (G15) — не в реальном времени (`W16` R3).
- **След:** следы миграции у переходов (`L05`, Срез).
- **Слух:** нет своего.
- **Сохраняется:** граф выводится из seed; хранятся раскрытый туман и последнее увиденное по локациям (`U05`, `W10`).

## 7. Интерфейс и управление
Кнопок не занимает. Карта этажа строится из увиденного (`U05`); иконки переходов различают «на этаже / вверх /
вниз» и появляются, только когда переход увиден. Схема «ярусы → этажи → пробуждённые якоря». Метки игрока разрешены.

## 9. Контент и производство
- **Прототип:** данные — параметры графа по этажам; инструмент — отладочный просмотр графа с полосами плотности
  и бюджетом добычи; пакетная проверка 1000 seed; иконки переходов для карты. Ассеты переходов — `W16`.
- **Срез:** рёбра через Врата, тайные ходы (`W15`).
- **Гл1:** рёбра между 11 ярусами.

## 10. Граничные случаи и эксплойты
- **Бег Искрой на верхний этаж** — распад мягко не пускает; выжил и нашёл что-то — законно (свобода).
- **Локация-мост.** Если все маршруты вверх идут через одну локацию, а там мини-босс, мягкий барьер становится
  фактически жёстким. Валидация: нет единственной локации, через которую проходят все пути между этажами
  *(ориентир)*.
- **Спуск ради фарма** — не окупается: давление и скудная добыча (`W07`).
- **Возврат тем же путём** всегда возможен (R3): игрок не застревает в плотной локации без выхода.
- **Выбить всю добычу этажа** — популяции восстанавливаются из запаса, последние особи вида в ярусе не съедаются (G5).

## 13. Проверка в прототипе
- Плейтестеры находят не меньше двух разных путей на следующий этаж.
- Никто не упирается в тупик без выхода.
- 1000 seed: связность, ≥ 2 перехода вверх, нет локации-моста, бюджет добычи выполнен.
- Игроки хотя бы раз за сессию добровольно возвращаются вниз (за ключом, лутом, Эхо).
